    Attention Is All You Need

    มกราคม 1, 2026
    Attention, Transformers, Neural Networks

    ชื่อชุดนี้คือ จากรีเลย์สู่ Attention ทุกอย่างจนถึงจุดนี้คือเส้นทางทางกายภาพและสถาปัตยกรรมอันยาวที่ทำให้การคูณเมทริกซ์ขนาดใหญ่เป็นไปได้จริง บทนี้คือจุดหมายเชิงอัลกอริทึมที่เส้นทางนั้นเปิดทางให้

    ในปี 2017 Vaswani et al. ตีพิมพ์ “Attention Is All You Need” เปเปอร์แนะนำ Transformer และทำให้ self-attention เป็นกลไกหลักในการจำลองลำดับ — แทนที่การเกิดซ้ำแบบลำดับของ RNN และ LSTM ด้วยปฏิบัติการที่ขนานได้อย่างเต็มที่ ซึ่งมองทุกตำแหน่งพร้อมกันได้

    Self-Attention ทำอะไร#

    เมื่อได้ token embedding แล้ว self-attention คำนวณ สำหรับทุกตำแหน่ง ผลรวมแบบถ่วงน้ำหนักของ value จากทุกตำแหน่ง น้ำหนักมาจากความคล้ายระหว่าง query (ตำแหน่งปัจจุบัน) กับ keys (ทุกตำแหน่ง) ในรูปเมทริกซ์:

    [ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V ]

    • (Q), (K) และ (V) คือการฉายเชิงเส้นของอินพุต
    • การสเกลด้วย (\sqrt{d_k}) ช่วยไม่ให้ softmax อิ่มตัวเมื่อมิติใหญ่
    • ผลลัพธ์คือลำดับความยาวเท่าเดิม ที่แต่ละตำแหน่งรวบรวมจากทุกตำแหน่งอื่นในแบบที่ขึ้นกับข้อมูล

    เพราะปฏิบัติการคือ matmul บวก softmax มันแมปเข้าฮาร์ดแวร์ของบทก่อนได้: หน่วย MAC ปริมาณงานสูง หน่วยความจำบนชิปขนาดใหญ่ อินเตอร์คอนเนกต์ที่เคลื่อน activation และน้ำหนัก

    Multi-Head Attention#

    หัวเดียวมักเรียนรู้ความสัมพันธ์ชนิดเดียว Multi-head attention รันหลายหัวขนาน (การฉายที่เรียนรู้ต่างกัน) แล้วต่อเข้าด้วยกัน — เชิงวากยสัมพันธ์ เชิงความหมาย เชิงตำแหน่ง ระยะไกลและใกล้ ในชั้นเดียวกัน

    Transformer ต้นฉบับใช้ 8 หัว LLM สมัยใหม่มักใช้หลายสิบถึงหลักร้อยต่ำของ query head ต่อชั้น (เช่น GPT-3: 96; Llama 3 405B: 128) ข้ามหลายสิบถึงราว 100+ ชั้น (Llama 3 405B: 126) — ไม่ใช่ “หลายร้อย” ของทั้งสองอย่างเป็นประจำ

    เหตุใดจึงครองสนาม#

    1. ความขนาน — ต่างจาก RNN ทุกตำแหน่งรันพร้อมกันได้ ปริมาณงานเทรนปรับตามความยาวลำดับและความจุ matmul ของฮาร์ดแวร์ ไม่ใช่ขั้นตอนตามลำดับ
    2. การพึ่งพาระยะไกล — โดยหลักการโทเคนใดใส่ใจโทเคนอื่นได้โดยตรง จำกัดด้วยเมทริกซ์ attention กำลังสองและ context window ในทางปฏิบัติ
    3. ความเข้ากันได้กับฮาร์ดแวร์ — งานหลักคือการคูณเมทริกซ์หนาแน่น — พอดีกับสิ่งที่ tensor core, systolic array และลำดับชั้นหน่วยความจำ GPU สมัยใหม่ถูกปรับให้เหมาะสม (บทที่ 55–58)

    ต้นทุนกำลังสองของ full attention ยังจริง — จึงมี sparse, linear, sliding-window และ approximation อื่น ข้อสังเกตหลักยังยืน: กลไก attention ที่เรียบง่ายและขนานได้แทนที่การเกิดซ้ำได้

    การปิดเส้นโค้ง#

    จากรีเลย์แม่เหล็กไฟฟ้าที่ทำให้ตรรกะบูลีนเป็นจริง ผ่านหลอด ทรานซิสเตอร์ ไปป์ไลน์ แคช GPU และ tensor core เส้นทางฮาร์ดแวร์ทำให้การสลับ การเก็บ และการคำนวณเลขคณิตเร็วขึ้น หนาแน่นขึ้น และมีประสิทธิภาพมากขึ้น Attention คือโครงสร้างเชิงอัลกอริทึมที่ปัจจุบันดึงคุณค่าจากฮาร์ดแวร์นั้นได้มากที่สุดสำหรับการจำลองลำดับ

    ข้อจำกัดทางกายภาพยังเปลี่ยน (แบนด์วิดท์หน่วยความจำ พลังงานต่อปฏิบัติการ ความหน่วงอินเตอร์คอนเนกต์) การตอบสนองทางวิศวกรรมยังเป็นรูปแบบเดียวกันตั้งแต่ต้นชุดนี้: ตั้งชื่อข้อจำกัดที่ผูกมัดให้แม่นยำ แล้วเปลี่ยนสถาปัตยกรรม แทนที่จะเพียงผลักแรงกว่าเดิมกับกำแพงเดิม

    นั่นคือเส้นด้ายต่อเนื่องจากรีเลย์สู่ attention

    ประตูออก: Ashish Vaswani, Noam Shazeer, Niki Parmar, Jakob Uszkoreit, Llion Jones, Aidan N. Gomez, Łukasz Kaiser และ Illia Polosukhin, “Attention Is All You Need” (NeurIPS 2017) — เปเปอร์ปฐมภูมิที่แนะนำ Transformer และทำให้ self-attention เป็นกลไกจำลองลำดับที่ครองสนาม
