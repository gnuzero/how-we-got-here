    กิตติกรรมประกาศและแหล่งข้อมูล#

    การเดินทางนี้ตั้งชื่อข้อจำกัดและคนในบทต่าง ๆ เมื่อหัวข้อมีต้นทางที่แข็งอยู่แล้ว เราชี้ไปที่นั่น Wikipedia เป็นแผนที่ ไม่ใช่ปลายทาง โต๊ะไทย สิงหล และทมิฬออกชื่อวรรณกรรมท้องถิ่นที่ตีพิมพ์แล้วเท่านั้น — ไม่เคยประดิษฐ์ชื่อเพื่อเติมช่องว่าง

    บทบาททีม (แนวคิด การเขียน โต๊ะภาษา) อยู่ที่ เกี่ยวกับ หน้านี้คือบันทึกวิชาชีพ ก่อน คำนำ เพื่อจะได้ไม่ต้องเดาว่าใครตีพิมพ์เนื้อหานี้ไปแล้ว

    มาตรฐานและสเปกต้นทาง#

    สเปกที่มีเลขและยังมีชีวิต ที่กระดูกสันหลังพิงอยู่แล้ว บ้านละหนึ่งที่ — ไม่ใช่สารบบทุกองค์กรมาตรฐาน

    • RFC Editor และ IETF — ชุด Request for Comments (Jon Postel เป็นบรรณาธิการเกือบสามทศวรรษ) ประตูออกที่อยู่ในบทแล้ว ได้แก่ RFC 1, RFC 791, RFC 793, RFC 1034, RFC 1035, RFC 1459, RFC 1591, RFC 6749, RFC 8446
    • IANA — พารามิเตอร์โพรโทคอลและทะเบียนตัวเลข
    • ICANN — ที่นั่งนโยบายชื่อและตัวเลข
    • Unicode Consortium — คลังอักขระร่วม (The Unicode Standard)
    • IEEE — ตระกูลชั้นลิงก์อย่าง IEEE 802 (Ethernet, Wi-Fi)
    • W3C และ WHATWG — ความหมายของแพลตฟอร์มเว็บ
    • PCI-SIG — PCI Express Base Specification
    • RISC-V International — คู่มือ ISA แบบเปิด
    • Free Software Foundation — GNU GPL สายสัญญาอนุญาตที่ถูกเอ่ยในบท Unix/Linux

    ประตูออกในบท (Baran, Tomasulo, Kung/Leiserson และที่เหลือ) อยู่ใน บทนั้น ๆ หน้านี้ไม่ซ้ำอีก

    งานอ้างอิง#

    Wikipedia และฉบับภาษาต่าง ๆ เป็นแผนที่กำหนดทิศ ตรวจกับต้นทางก่อนถือว่าหน้าหนึ่งจบแล้ว เราลิงก์ออก ไม่โฮสต์สารานุกรม

    Wikimedia Commons คือประตูภาพ (ดูด้านล่าง) ฉบับภาษา (ไทย, සිංහල, தமிழ்) คือแผนที่ ชนิดเดียวกัน สำหรับผู้อ่านเหล่านั้น

    ตำราด้านบนคืออ่านเพิ่มในบท นี่คือชั้นที่ขาด — ใครทำให้ภาษาไทย ใช้ได้ บนคอมพิวเตอร์

    เสียงที่ได้ยิน แต่ยังให้เครดิตไม่ได้#

    วันที่ 10 กันยายน 2026 Raz & Upgrade ออก Zunara บน Regroup Records คุณได้ยินผู้หญิงร้องเป็นภาษาสิงหล หน้าสโตร์บอกชื่อโปรดิวเซอร์และค่าย ไม่บอกชื่อนักร้อง

    หน้านี้อยู่เพื่อช่องว่างแบบนี้ การได้ยินใครสักคนไม่ใช่สัญญาอนุญาตให้ใช้เสียงของเขา และไม่ใช่ชื่อที่ใส่ในบรรทัดเครดิตได้

    สิ่งที่เขียนได้:

    • เพลง: Zunara — Raz & Upgrade (Raz Kfir), © 2026 Regroup Records เครื่องเล่นด้านบนเป็นของ Spotify สัญญาอนุญาตของพวกเขากับค่าย — ไม่ใช่ไฟล์ที่เราโฮสต์
    • ภาษาของท่อนฮุก: สิงหล คำแปลความ ไม่ใช่การคัดลอกเนื้อเพลง: มีคนซ่อนอยู่ท่ามกลางดวงดาว ซ่อนในความฝัน ถูกทิ้งไว้ตามลำพัง ถามว่าเมื่อไรจะมา

    สิ่งที่เขียนไม่ได้:

    • ชื่อนักร้อง ไม่มีชื่อที่เผยแพร่ เราไม่ประดิษฐ์ชื่อเพื่อเติมช่องว่าง
    • เครื่องหมาย Creative Commons บนแผ่นเสียง มันไม่ใช่ CC
    • สเต็มหรือริปที่เราโฮสต์ เสียงร้องที่แยกออกมาเป็นงานดัดแปลงของมาสเตอร์ © 2026 ใส่ไว้ในหนังสือ CC BY 4.0 คือการโกหกเรื่องไฟล์นั้น

    ถ้านักร้องหรือค่ายเผยแพร่เครดิตหรือสัญญาอนุญาตของแซมเปิลในภายหลัง บรรทัดนั้นจะมีชื่อ จนกว่านั้น เครดิตที่ซื่อสัตย์คือเครดิตที่ยังไม่มี
