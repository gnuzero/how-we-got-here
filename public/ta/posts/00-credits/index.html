    நன்றியுரையும் மூலாதாரங்களும்#

    இந்தப் பயணம் அத்தியாயங்களில் கட்டுப்பாடுகளையும் மக்களையும் பெயரிடுகிறது. ஒரு தலைப்புக்கு ஏற்கனவே வலுவான முதன்மை மூலம் இருக்கும்போது, நாங்கள் வெளியே சுட்டிக்காட்டுகிறோம். Wikipedia ஒரு வரைபடம்; இலக்கு அல்ல. சீன, தாய், சிங்கள, தமிழ் மேசைகள் வெளியிடப்பட்ட உள்ளூர் இலக்கியம் இருக்கும் இடங்களில் அதைப் பெயரிட்டுக் குறிப்பிடுகின்றன; இல்லாத இடத்தில் ஊகத்தால் நிரப்பாமல் இடைவெளியைத் திறந்தே விடுகின்றன.

    குழுப் பங்குகள் (கருத்துரு, எழுத்து, மேசைகள்) பற்றி பக்கத்தில் உள்ளன. இந்தப் பக்கம் முன்னுரைக்கு முன் உள்ள தொழில்முறை பதிவு — இந்தப் பொருளை ஏற்கனவே யார் வெளியிட்டார்கள் என்று யாரும் ஊகிக்க வேண்டாம்.

    தரநிலைகள் மற்றும் முதன்மை விவரக்குறிப்புகள்#

    முதுகெலும்பு ஏற்கனவே சார்ந்திருக்கும் வாழும், எண்ணிடப்பட்ட விவரக்குறிப்புகள். ஒவ்வொன்றிற்கும் ஒரு வீடு — ஒவ்வொரு தரநிலை அமைப்பும் அல்ல.

    • RFC Editor மற்றும் IETF — Request for Comments தொடர் (Jon Postel கிட்டத்தட்ட மூன்று பத்தாண்டுகள் அதைத் திருத்தினார்). அத்தியாயங்களில் ஏற்கனவே உள்ள வெளியேறும் கதவுகள்: RFC 1, RFC 791, RFC 793, RFC 1034, RFC 1035, RFC 1459, RFC 1591, RFC 6749, RFC 8446.
    • IANA — நெறிமுறை அளவுருக்கள் மற்றும் எண் பதிவுகள்.
    • ICANN — பெயர்கள் மற்றும் எண்கள் கொள்கை இருக்கை.
    • Unicode Consortium — பகிரப்பட்ட எழுத்துத் தொகுப்பு (The Unicode Standard).
    • IEEE — IEEE 802 போன்ற இணைப்பு-அடுக்கு குடும்பங்கள் (Ethernet, Wi-Fi).
    • W3C மற்றும் WHATWG — வலை தள அர்த்தம்.
    • PCI-SIG — PCI Express Base Specification.
    • RISC-V International — திறந்த ISA கையேடு.
    • Free Software Foundation — GNU GPL, Unix/Linux அத்தியாயங்களில் பெயரிடப்பட்ட உரிம வம்சாவளி.

    அத்தியாய வெளியேறும் கதவுகள் (Baran, Tomasulo, Kung/Leiserson, மற்றும் பிற) அந்த அத்தியாயங்களிலேயே இருக்கின்றன. இந்தப் பக்கம் அவற்றை மறுபதிப்பு செய்யாது.

    குறிப்புப் பணிகள்#

    Wikipedia மற்றும் அதன் மொழிப் பதிப்புகள் திசைகாட்டி வரைபடங்கள். ஒரு பக்கத்தைத் தீர்மானமாகக் கருதும் முன் முதன்மைக்கு எதிராகச் சரிபார்க்கவும். நாங்கள் வெளியே இணைக்கிறோம்; கலைக்களஞ்சிய உரையை நாங்கள் ஹோஸ்ட் செய்வதில்லை.

    Wikimedia Commons படக் கதவு (கீழே பார்க்கவும்). மொழிப் பதிப்புகள் (中文, ไทย, සිංහල, தமிழ்) அந்த வாசகர்களுக்கு அதே வகையான வரைபடம்.
