    Attention Is All You Need

    ஜனவரி 1, 2026
    Attention, Transformers, Neural Networks

    இந்தத் தொடரின் தலைப்பு ரிலேயிலிருந்து Attention வரை. இதுவரை வந்த அனைத்தும், பெரிய அளவிலான matrix multiplication-ஐ நடைமுறைக்குக் கொண்டுவந்த நீண்ட இயற்பியல் மற்றும் கட்டமைப்புப் பாதை. இந்த அத்தியாயம் அந்தப் பாதை சாத்தியமாக்கிய அல்காரித இலக்கு.

    தமிழ் இடைவெளிக் குறிப்பு: Transformer, attention, பெருமொழி மாதிரிகள் (LLM) பற்றித் தமிழ் எழுத்து விளக்கம் மெலிதானது; காணொளிச் சான்று YouTube தேடல் முடிவுகள் மட்டும் — காணொளிகள் பார்க்கப்படவில்லை. கீழே உள்ள Transformer அளவுகள் (d_model 512, 8 heads, d_k 64, 6 அடுக்குகள், 65 M parameters; big: 16 heads, 213 M), √d_k காரணம், Table 1 சிக்கல்கள், பயிற்சி நேரங்கள், FLOPs மதிப்பீடு ஆகியவை ஆங்கிலப் பதிவின் “Door out” கட்டுரையிலிருந்து (Vaswani et al., arXiv 1706.03762v7) சரிபார்க்கப்பட்டவை. கையால் செய்த attention கணக்கை எங்கள் பணிக் கணினியில் NumPy, PyTorch-இன் scaled_dot_product_attention இரண்டாலும் சரிபார்த்தோம். Q, K, V எண்கள், வரிசை நீளங்கள் “எடுத்துக்காட்டு மதிப்புகள்”. இந்தப் பதிவுக்கு lab இல்லை; காகிதப் பயிற்சிகள் கீழே.

    முதலில் சொற்கள்#

    • Token / embedding (டோக்கன் / உட்பொதிப்பு): உரையின் ஒரு துண்டு / அதைக் குறிக்கும் எண் vector.
    • Query, key, value (வினவல், திறவு, மதிப்பு): ஒவ்வொரு நிலையின் உள்ளீட்டிலிருந்து மூன்று கற்ற matrix-களால் பெறப்படும் மூன்று vector-கள்.
    • Dot product (புள்ளிப் பெருக்கம்): இரு vector-களின் உறுப்புவாரிப் பெருக்கங்களின் கூட்டுத்தொகை — ஒற்றுமையின் அளவு.
    • Softmax: எண்களை அடுக்குக்குறி (eˣ) மூலம் நேர்மமாக்கி, கூட்டுத்தொகை 1 ஆகும்படி வகுப்பது — எடைகளாக்குதல்.
    • d_k: ஒவ்வொரு key / query vector-இன் பரிமாணம்.
    • Head (தலை): தனி projection-களுடன் ஓடும் ஒரு attention கணக்கு; multi-head = பல இணையாக.
    • Recurrence (மீள்நிகழ்வு): RNN/LSTM போல, ஒரு நிலையைக் கணிக்க முந்தைய நிலையின் முடிவு தேவைப்படுவது — வரிசையாக மட்டுமே ஓடும்.
    • இருபடிச் செலவு (quadratic cost): வரிசை நீளம் n இருமடங்கானால் attention matrix n × n நான்கு மடங்காவது.

    2017இல், Vaswani et al. “Attention Is All You Need”-ஐ வெளியிட்டனர். அந்தக் கட்டுரை Transformer-ஐ அறிமுகப்படுத்தி self-attention-ஐ வரிசைகளை மாதிரியாக்குவதற்கான முதன்மைப் பொறிமுறையாக ஆக்கியது — RNN மற்றும் LSTM-இன் வரிசைமுறை மீள்நிகழ்வை, ஒவ்வொரு நிலையையும் ஒரே நேரத்தில் பார்க்கக்கூடிய முழுமையாக இணைச்செயலாக்கக்கூடிய செயல்பாட்டால் மாற்றியது.

    Self-Attention என்ன செய்கிறது#

    டோக்கன் உட்பொதிப்புகள் கொடுக்கப்பட்டால், self-attention ஒவ்வொரு நிலைக்கும் எல்லா நிலைகளிலும் உள்ள மதிப்புகளின் எடையிடப்பட்ட சேர்க்கையைக் கணிக்கிறது. எடைகள் ஒரு query (தற்போதைய நிலை) மற்றும் keys (ஒவ்வொரு நிலை) இடையேயான ஒற்றுமையிலிருந்து வரும். மேட்ரிக்ஸ் வடிவில்:

    [ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V ]

    • (Q), (K), மற்றும் (V) உள்ளீட்டின் நேரியல் projections (வீழ்ப்புகள்).
    • (\sqrt{d_k}) ஆல் அளவிடுவது பரிமாணம் பெரியதாக இருக்கும்போது softmax நிறைவுறுவதைத் தடுக்கிறது.
    • முடிவு அதே நீளத்தின் வரிசை; ஒவ்வொரு நிலையும் தரவு-சார்ந்த வழியில் மற்ற எல்லாவற்றிலிருந்தும் சேகரித்தது.

    Attention கையால் — ஒரு query, மூன்று டோக்கன்கள்#

    d_k = 2. ஒரு query q = [1, 0]. மூன்று நிலைகளின் keys, values (எடுத்துக்காட்டு மதிப்புகள்):

    நிலை key k value v q · k ÷ √2 e^( ) softmax எடை
    1 [1, 0] [1, 0] 1 0.707 2.028 2.028 ÷ 5.056 ≈ 0.401
    2 [0, 1] [0, 1] 0 0 1.000 1.000 ÷ 5.056 ≈ 0.198
    3 [1, 1] [0.5, 0.5] 1 0.707 2.028 2.028 ÷ 5.056 ≈ 0.401

    (2.028 + 1.000 + 2.028 = 5.056.) வெளியீடு = எடையிட்ட values-இன் கூட்டுத்தொகை:

    0.401 × [1, 0] + 0.198 × [0, 1] + 0.401 × [0.5, 0.5] = [0.401 + 0.2005, 0.198 + 0.2005] ≈ [0.602, 0.398].

    NumPy [0.6017, 0.3983] என்றும், PyTorch-இன் scaled_dot_product_attention அதே [0.6017, 0.3983] என்றும் தந்தன (கையால் செய்ததில் சிறு வேறுபாடு rounding காரணம்). q-வுடன் ஒத்த key கொண்ட நிலைகள் 1, 3 அதிக எடை பெற்றன — “தரவு சார்ந்த சேகரிப்பு” இதுதான். முழு Q matrix-உடன் இது எல்லா நிலைகளுக்கும் ஒரே matmul-ஆக நடக்கிறது.

    √d_k ஏன்? கட்டுரையின் விளக்கம்: q, k-இன் உறுப்புகள் சராசரி 0, variance 1 கொண்ட சார்பற்ற மாறிகள் என்றால், q · k-இன் variance = d_k. d_k = 64 என்றால் திட்ட விலக்கம் √64 = 8. எங்கள் கணினியில் 100,000 சீரற்ற 64-பரிமாண ஜோடிகளில் அளந்தது: திட்ட விலக்கம் ≈ 8.00; √64 = 8-ஆல் வகுத்த பிறகு ≈ 1.00.

    ஏன் முக்கியம்? இரண்டு மதிப்பெண்கள் [8, 0] என்றால் softmax [0.9997, 0.0003] — கிட்டத்தட்ட ஒன்றே வெல்கிறது, மற்றதன் gradient கிட்டத்தட்ட பூஜ்யம் (நிறைவுறுதல்). 8-ஆல் வகுத்த [1, 0]-க்கு softmax [0.731, 0.269] — கற்றலுக்கு இடம் இருக்கிறது.

    Op matmuls மற்றும் ஒரு softmax ஆதலால், முந்தைய அத்தியாயங்களின் வன்பொருள் மீது வரைபடமாகிறது: உயர்-throughput MAC அலகுகள், பெரிய on-chip நினைவகங்கள், activations மற்றும் weights நகர்த்தும் interconnects.

    Multi-Head Attention#

    ஒரு head ஒரு வகையான உறவைக் கற்றுக்கொள்ளும் போக்குடையது. Multi-head attention பலவற்றை இணைச்செயலாக இயக்குகிறது (வேறுபட்ட கற்றுக்கொள்ளப்பட்ட projections) மற்றும் இணைக்கிறது — அதே அடுக்கில் தொடரியல், பொருண்மை, நிலைசார்ந்த, நீண்ட- மற்றும் குறுகிய-தூரம்.

    அசல் Transformer-இன் base model 8 heads பயன்படுத்தியது (big model 16). நவீன LLM-கள் பொதுவாக ஒரு அடுக்குக்குப் பத்து முதல் குறைந்த நூற்றுக்கணக்கான query heads (எ.கா. GPT-3: 96; Llama 3 405B: 128) பத்து முதல் ~100+ அடுக்குகள் வரை (Llama 3 405B: 126) — இருபக்கமும் வழக்கமாக “நூற்றுக்கணக்கானவை” அல்ல.

    அசல் Transformer-இன் அளவுகள் (கட்டுரை, Table 3)#

    அடுக்குகள் N d_model heads h d_k = d_model ÷ h parameters
    base 6 512 8 512 ÷ 8 = 64 65 M
    big 6 1024 16 1024 ÷ 16 = 64 213 M

    ஒவ்வொரு head-இன் பரிமாணமும் குறைவு (64) என்பதால், 8 heads-இன் மொத்தக் கணக்குச் செலவு முழுப் பரிமாணத்தில் ஒரு head-இன் செலவுக்கு “ஒத்தது” என்கிறது கட்டுரை — heads கூடுதல் கணக்கு அல்ல, அதே கணக்கைப் பிரித்தல். (“அசல் Transformer 8 heads” என்பது base model-க்குப் பொருந்தும்; big model 16 heads பயன்படுத்தியது.)

    அது ஏன் மேலாதிக்கமானது#

    1. இணைச்செயலாக்கம் — RNN-களைப் போலல்லாமல், ஒவ்வொரு நிலையும் ஒரே நேரத்தில் ஓடலாம். பயிற்சி throughput வரிசை நீளம் மற்றும் வன்பொருள் matmul திறனுடன் சேர்ந்து வளர்கிறது, வரிசைமுறை படிகளால் கட்டுப்படுவதில்லை.
    2. நீண்ட-தூர சார்பு — கொள்கையளவில் எந்த டோக்கனும் வேறு எதற்கும் நேரடியாகக் கவனம் செலுத்தலாம், இருபடி attention மேட்ரிக்ஸ் மற்றும் நடைமுறை context windows ஆல் வரம்பிடப்பட்டது.
    3. வன்பொருள் இணக்கம் — மேலாதிக்க வேலை அடர்த்தியான matrix multiplication — tensor cores, systolic arrays மற்றும் நவீன GPU நினைவக படிநிலைகள் உகந்ததாக்கப்பட்டது சரியாக (பதிவுகள் 55–58).

    முழு attention-இன் இருபடிச் செலவு இன்னும் உண்மை — எனவே sparse, linear, sliding-window மற்றும் பிற தோராயங்கள். மைய உள்ளுணர்வு இன்னும் நிற்கிறது: எளிய, இணைச்செயலாக்கக்கூடிய attention பொறிமுறை மீள்நிகழ்வை மாற்ற முடியும்.

    இருபடிச் செலவு மற்றும் இணைச்செயலாக்கம், எண்களில்#

    வளைவை மூடுதல்#

    Boolean தர்க்கத்தைச் செயல்படுத்திய மின்காந்த ரிலேக்களிலிருந்து, குழாய்கள், டிரான்சிஸ்டர்கள், pipelines, caches, GPU-கள் மற்றும் tensor cores வழியாக, வன்பொருள் பாதை மாறுதல், சேமிப்பு மற்றும் கணிதத்தை வேகமாகவும், அடர்த்தியாகவும், திறமையாகவும் ஆக்கியது. Attention என்பது வரிசை மாதிரியாக்கத்திற்காக அந்த வன்பொருளிலிருந்து தற்போது அதிக மதிப்பைப் பிரித்தெடுக்கும் அல்காரித கட்டமைப்பு.

    இயற்பியல் கட்டுப்பாடுகள் தொடர்ந்து மாறுகின்றன (நினைவக bandwidth, ஒரு op-க்கு ஆற்றல், interconnect latency). பொறியியல் பதில் இந்தத் தொடரின் தொடக்கத்திலிருந்தே அதே pattern: பிணைப்புக் கட்டுப்பாட்டைத் துல்லியமாகப் பெயரிடுங்கள், பிறகு அதே சுவருக்கு எதிராகக் கடினமாகத் தள்ளுவது மட்டும் அல்லாமல் கட்டமைப்பை மாற்றுங்கள்.

    அதுவே ரிலேக்களிலிருந்து attention வரையிலான தொடர்ச்சியான நூல்.
