    ස්තුතිය සහ මූලාශ්‍ර#

    මෙම ගමන පරිච්ඡේද තුළ සීමා සහ පුද්ගලයන් නම් කරයි. මාතෘකාවකට දැනටමත් ශක්තිමත් මූලික මූලාශ්‍රයක් ඇති විට, අපි පිටතට යොමු කරමු. Wikipedia සිතියමකි, ගමනාන්තය නොවේ. තායි, සිංහල, සහ දෙමළ මේස ප්‍රකාශිත දේශීය සාහිත්‍යය නම් කරන්නේ එය සැබවින්ම පවතින විට පමණි — හිඩැසක් පුරවන්නට නිර්මාණය කළ නමක් නොවේ.

    කණ්ඩායම් භූමිකා (සංකල්පය, ලේඛනය, මේස) පිළිබඳව පිටුවේ ඇත. මෙම පිටුව පෙරවදනට පෙර වෘත්තීය වාර්තාවයි — මෙම ද්‍රව්‍ය දැනටමත් ප්‍රකාශ කළේ කවුදැයි කිසිවෙකුට උපකල්පනය කිරීමට අවශ්‍ය නොවේ.

    ප්‍රමිති සහ මූලික විශේෂණ#

    කොඳු නාරටිය දැනටමත් රැඳෙන ජීවමාන, අංකිත විශේෂණ. එකින් එක එක නිවසක් — සෑම ප්‍රමිති ආයතනයකම catalog එකක් නොවේ.

    • RFC Editor සහ IETF — Request for Comments මාලාව (Jon Postel එය සංස්කරණය කළේ ආසන්න වශයෙන් දශක තුනක්). පරිච්ඡේදවල දැනටමත් ඇති පිටවීමේ දොරවල්: RFC 1, RFC 791, RFC 793, RFC 1034, RFC 1035, RFC 1459, RFC 1591, RFC 6749, RFC 8446.

    • IEEE — IEEE 802 වැනි link-layer පවුල් (Ethernet, Wi-Fi).

    • Free Software Foundation — GNU GPL, Unix/Linux පරිච්ඡේදවල නම් කළ බලපත්‍ර පරම්පරාව.

    පරිච්ඡේද පිටවීමේ දොරවල් (Baran, Tomasulo, Kung/Leiserson, සහ ඉතිරිය) එම පරිච්ඡේද තුළම රැඳේ. මෙම පිටුව ඒවා නැවත මුද්‍රණය නොකරයි.
