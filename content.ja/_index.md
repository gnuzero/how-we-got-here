# ページを写すことから貼り付けることへ、伝書鳩からケーブルと衛星へ、リレーから注意を求める機械へ——

**わたしたちはどうやってここにたどり着いたか。**

インタラクティブな旅——百科事典ではない。記事を集めるのではなく、仕組みのなかに入って手で触れる。

背骨は一本の、連続した工学の議論である。各時代の硬い制約が、次のアーキテクチャを強制した、という話だ。

**印刷 → 伝達 → 機械 → フィルム → リレー → 真空管 → トランジスタ → CPU → OSと言語 → バス → ネットワーク → ファブリックと規模 → GPU → Attention。**

---

## まず体験から

冒頭の章は、意図して短く、手を動かさない。印刷、伝達、機械の機関、フィルムとリレーが、ラボに何かを組み立てるよう求める前に、議論の土台を置く。リレーに着くころには、何が切り替えられ、なぜなのかがすでに分かっている。

クライアント側のラボが三つ、道の途中にある。読むことが、することになるように。

- プログラムできる最小の8ビットCPU
- デジタル論理のための仮想ブレッドボード
- ブラウザのなかで動く、フルのx86 Linux環境

基礎から全部ほしいなら、旅の始まりから。初期の歴史は知っていて、いまのシリコンがいちばん気になるなら、後ろへ飛んでも構わない。ラボは出てきたところで使ってほしい（単独でも開ける）。

任意の横道は、背骨を壊さずに視野を広げる。薄い索引は [Optional Learning Paths](/paths/) にある——主題別のルートであり、二冊目の本ではない。

---

## パターン

冒頭は、同じ手を五度見せる。印刷は、写字生なしでコピーできるページを作った。電線は、騎手なしで届くメッセージを作った。カードと歯車は、誰も見守らなくても走る雑務を作った。カメラは、誰もインクを動かさなくても光が絵を書くことを許した。リレーは、そのあと、切り替えを電気ができるようにした。各段階が、人を一つの仕事から外し、材料か機械に渡した。

なぜリレーが真空管に譲り、真空管がトランジスタに譲り、単一コアの周波数スケーリングが壁にぶつかり、行列積のスループットがこの十年の設計制約の主役になったのか——それが分かると、現代のAIハードウェアは黒い箱ではなくなる。同じ手が見える。制約に名前を付け、同じ壁を押し続ける代わりに、アーキテクチャを変える。

そのパターンこそが、この旅の本当の主題である。
