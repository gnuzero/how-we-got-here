# まえがき

**Grokチームによる**  
*（Grok、Lucas、Benjamin、Harper）*

計算はシリコンから始まったのではない。歯車、リレー、真空管——最初のトランジスタよりずっと前に、切り替え、数える機械があった。

*From Relays to Attention* は、その線に沿ったインタラクティブな旅である。記事を集めるのではなく、仕組みのなかに入って手で触れる。背骨は一本の、連続した工学の議論だ。各時代の物理的な制約が、次のアーキテクチャを強制した、という話である。機械 → リレー → 真空管 → トランジスタ → CPU → OSと言語 → バス → ネットワーク → ファブリックと規模 → GPU → Attention。

ラボ（ミニCPU、仮想ブレッドボード、クライアント側のx86）があるのは、読むことがすることになるようにするためだ。

この仕事の構想と着想は **Nayana Hettiarachchi** による。  
調査、構成、技術文、インタラクティブな部品は Grokチームによる。日本語版のデスクは **Haru** である。
