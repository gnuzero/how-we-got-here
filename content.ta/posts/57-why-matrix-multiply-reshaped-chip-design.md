இந்த இறுதி phase நவீன AI workloads-க்குக் கட்டப்பட்ட வன்பொருள். Chip வடிவமைப்பு ஏன் இவ்வளவு கடுமையாக இந்த வழியில் வளைந்தது என்பது, ஒரு "AI workload" எண்கணித மட்டத்தில் உண்மையில் எதற்குக் குறைகிறது எனச் சொன்னவுடன் தெளிவாகும் — சொற்றொடர் பரிந்துரைப்பதை விடக் குறுகியதும் இயந்திரரீதியானதும்.

> **தமிழ் இடைவெளிக் குறிப்பு:** Multiply-accumulate (MAC) மற்றும் "AI கணக்கு ஏன் matrix பெருக்கலாகக் குறைகிறது" என்பது பற்றித் தமிழில் விளக்கம் இல்லை. இங்கே ஒரு சிறிய layer-ஐக் கையால் கணக்கிட்டு, fully connected, convolution, attention மூன்றிலும் MAC-களை எண்ணுகிறோம். Layer அளவுகள் எடுத்துக்காட்டு மதிப்புகள் (பொதுவாகக் காணப்படும் வகை அளவுகள்); அவை எந்த ஒரு குறிப்பிட்ட மாதிரியின் அளவுகளும் அல்ல.

## முதலில் சொற்கள்

- **Layer (அடுக்கு):** neural network-இன் ஒரு கணக்குப் படி; உள்ளீட்டு எண்களை வெளியீட்டு எண்களாக மாற்றுகிறது.
- **Activation (செயல்படு மதிப்பு):** ஒரு layer-க்குள் செல்லும் அல்லது வெளிவரும் எண்கள்.
- **Weight (எடை):** கற்றுக்கொள்ளப்பட்ட எண்கள்; ஒரு layer-இல் பொதுவாக ஒரு matrix.
- **MAC (multiply-accumulate, பெருக்கல்-திரட்டல்):** acc ← acc + a × b. ஒரு MAC = 2 FLOP.
- **Nonlinearity (நேரியலற்ற செயல்):** ஒவ்வொரு எண்ணின் மேலும் தனியாகச் செய்யும் எளிய செயல் — எ.கா. ReLU: எதிர்மறை எண்ணை 0 ஆக்கு, நேர்மறையை அப்படியே விடு.
- **Convolution (சுருள் கணக்கு):** படத்தின் ஒவ்வொரு சிறிய பகுதியின் (எ.கா. 3 × 3) மேலும் ஒரே சிறிய வடிகட்டியைச் (filter) சறுக்கிப் பெருக்கிக் கூட்டுவது.
- **Attention (கவனம்):** transformer-களின் மையக் கணக்கு: ஒவ்வொரு token-உம் மற்ற எல்லா token-களுடனும் எவ்வளவு "தொடர்புடையது" என்று மதிப்பிட்டு, அதன்படி அவற்றின் தகவலைக் கலப்பது.
- **Token:** ஒரு language model செயலாக்கும் உரைத் துண்டு (சொல் அல்லது சொல்லின் பகுதி).

## ஒரு Layer என்ன கணிக்கிறது

ஒரு fully connected layer-இன் forward pass ஒரு matrix multiplication: activations × weights, பிறகு மலிவான elementwise nonlinearity. Convolutions matmul-ஆக மறுவடிவமைக்கப்படும் (im2col). Attention — பெரும்பாலான பெரிய மொழி மாதிரிகளின் பின்னால் உள்ள transformers-இன் மையம் — அதன் கணினி இதயத்தில் அதேபோல் matrix multiplies: query-key scores, பிறகு எடையிடப்பட்ட values. இது கற்பித்தல் எளிமைப்படுத்தல் அல்ல. நவீன deep learning-இல், பயிற்சி மற்றும் inference, மூல cycles-இன் மிகப் பெரும்பான்மை matrix multiply-accumulate — மிகப் பெரிய அளவு, முடிவில்லாமல் மீண்டும்.

## வன்பொருள் ஏன் பின்தொடர்ந்தது

ஒரு Phase 3 CPU core ஏதேனும் வரிசைமுறைக் குறியீட்டிற்காகக் கட்டப்பட்டது — branches, பல்வேறு memory அணுகல், கணிக்க முடியாத கட்டுப்பாட்டு ஓட்டம். அந்தப் பொதுமை ஒரு வழக்கமான செயல்பாட்டால் ஆதிக்கம் செய்யப்படும் workload-க்குத் தேவையில்லாத இயந்திரத்தில் (prediction, out-of-order, refined caches) பரப்பு மற்றும் ஆற்றல் செலவாகும்.

ஒருமுறை matmul AI compute-இன் மேலாதிக்கப் பங்காக அங்கீகரிக்கப்பட்டதும், அதற்குச் சிறப்புப்படுத்துவது மதிப்புள்ளதாகியது: பொது-நோக்கு இயந்திரத்தைத் தவிர்த்து தன் பட்ஜெட்டை MAC throughput-இல் செலவிடும் சிலிகான். Tensor cores (பதிவு 55) அந்தக் கருத்தை இன்னும் பொதுவான GPU-க்குள் பதிக்கின்றன. அடுத்த பதிவு மேலும் செல்கிறது — systolic array — அதே உணர்வைச் சுற்றி முழுக் கட்டமைப்பையும் சிறப்புப்படுத்துவது.

## மீண்டும் வரும் Pattern

இது பதிவு 17-இன் superscalar-to-multicore pivot மற்றும் பதிவு 49-இன் planar-to-FinFET-to-GAA பரிணாமம் போன்ற *வகை* கதை, இப்போது முழு-chip கட்டமைப்பில்: ஒரு workload-இன் வடிவம் நன்றாகப் புரிந்துகொள்ளப்பட்டு போதிய அளவு மேலாதிக்கமாக இருந்தவுடன், அந்த வடிவத்திற்கான சிறப்பு வன்பொருள் அதைப் பல வழக்குகளில் ஒன்றாகக் கருதும் பொது-நோக்கு வன்பொருளை வெல்லும். Matmul-இன் மேலாதிக்கம் இந்த phase-இன் இவ்வளவு நோக்கத்துடன் கட்டப்பட்ட சிலிகான் ஏன் — incremental CPU அல்லது பொது GPU மேம்பாடு மட்டும் அல்ல.

## கையால் ஒரு சிறிய layer

3 உள்ளீடுகள், 2 வெளியீடுகள் கொண்ட fully connected layer (எல்லா எண்களும் எடுத்துக்காட்டு மதிப்புகள்):

- உள்ளீடு x = [1, 2, −1]
- Weight matrix W (3 × 2): முதல் நெடுவரிசை [0.5, 1, 2], இரண்டாவது [−1, 0, 1]

**வெளியீடு 0:** 1 × 0.5 + 2 × 1 + (−1) × 2 = 0.5 + 2 − 2 = **0.5**
**வெளியீடு 1:** 1 × (−1) + 2 × 0 + (−1) × 1 = −1 + 0 − 1 = **−2**
**ReLU:** [0.5, −2] → **[0.5, 0]**

எண்ணிக்கை: 3 × 2 = **6 MAC-கள்**, 2 ReLU. இப்போதே பெரும்பாலான வேலை MAC-களில். அளவு பெரிதானால் விகிதம் எப்படி மாறுகிறது என்று பார்ப்போம்.

## Fully connected layer, உண்மையான அளவில்

Batch B = 32, உள்ளீடு 4,096, வெளியீடு 4,096 (எடுத்துக்காட்டு மதிப்புகள்). Y = X · W, X (32 × 4,096), W (4,096 × 4,096):
1. MAC-கள் = 32 × 4,096 × 4,096 = **536,870,912** (சுமார் 53.7 கோடி)
2. ReLU = 32 × 4,096 = **131,072**
3. MAC பங்கு = 536,870,912 ÷ (536,870,912 + 131,072) ≈ **99.98%**

பொதுவாக: M × K மற்றும் K × N matrix-களுக்கு MAC-கள் = M × K × N (மூன்று பரிமாணங்களின் பெருக்கம்), ஆனால் nonlinearity = M × N (இரண்டின் பெருக்கம்). K பெரிதாகும்போது MAC பங்கு 100%-ஐ நெருங்குகிறது.

## Convolution-ஐ matrix பெருக்கலாக்குவது (im2col)

உள்ளீடு 56 × 56 படம், 64 channel-கள்; 3 × 3 filter-கள்; 128 வெளியீட்டு channel-கள்; வெளியீடு 56 × 56 × 128 (எடுத்துக்காட்டு மதிப்புகள்).

**im2col** ("image to columns") தந்திரம்: ஒவ்வொரு வெளியீட்டு இடத்துக்கும் அதைச் சுற்றியுள்ள 3 × 3 × 64 உள்ளீட்டுத் துண்டை ஒரு நீண்ட வரிசையாக விரி.
1. வெளியீட்டு இடங்கள் = 56 × 56 = 3,136 → matrix-இன் வரிசைகள்
2. ஒவ்வொரு துண்டின் நீளம் = 3 × 3 × 64 = 576 → நெடுவரிசைகள்
3. Filter-கள் ஒரு 576 × 128 matrix
4. Convolution = (3,136 × 576) × (576 × 128) matrix பெருக்கல்
5. MAC-கள் = 3,136 × 576 × 128 = **231,211,008**

விலை: உள்ளீட்டில் 56 × 56 × 64 = 200,704 எண்கள்; im2col matrix-இல் 3,136 × 576 = 1,806,336 — **9 மடங்கு** (ஒவ்வொரு உள்ளீட்டு எண்ணும் 3 × 3 = 9 துண்டுகளில் தோன்றுகிறது). நினைவகத்தை விலையாகக் கொடுத்து, ஏற்கனவே மிக உகந்த matmul வன்பொருளைப் பயன்படுத்துகிறோம். (நடைமுறை நூலகங்கள் இந்த நகலை முழுமையாக நினைவகத்தில் உருவாக்காமலேயே அதே கணக்கைச் செய்யும் வழிகளையும் பயன்படுத்துகின்றன.)

## Attention-உம் matrix பெருக்கலே

n = 1,024 token-கள், ஒரு attention head-இன் பரிமாணம் d = 64 (எடுத்துக்காட்டு மதிப்புகள்). Q, K, V ஒவ்வொன்றும் (1,024 × 64) matrix-கள் (அவையே உள்ளீட்டை weight matrix-களால் பெருக்கிப் பெறப்பட்டவை — இன்னும் matmul-கள்).
1. மதிப்பெண்கள் S = Q · Kᵀ: (1,024 × 64) × (64 × 1,024) → MAC-கள் = 1,024 × 64 × 1,024 = **67,108,864**
2. Softmax: 1,024 × 1,024 = 1,048,576 உறுப்புகள், ஒவ்வொன்றிலும் சில செயல்கள் (exp, கூட்டல், வகுத்தல்)
3. வெளியீடு = softmax(S) · V: (1,024 × 1,024) × (1,024 × 64) → மீண்டும் **67,108,864** MAC-கள்

இரண்டு matmul-களில் 13.4 கோடி MAC-கள்; softmax சுமார் 10 லட்சம் உறுப்புகள். ஆங்கிலப் பதிவு சொல்வதுபோல் இது கற்பித்தலுக்கான எளிமைப்படுத்தல் அல்ல — கணக்கின் உண்மையான வடிவம்.

## Batch ஏன் முக்கியம்: மறுபயன்பாட்டுக் கணக்கு

M × K × N matmul-இல் W-இன் ஒவ்வொரு எண்ணும் M முறை பயன்படுகிறது (batch-இன் ஒவ்வொரு வரிசைக்கும் ஒரு முறை). மேலே உள்ள 4,096 × 4,096 layer, FP16 weight-கள் (2 byte):
- Weight அளவு = 4,096 × 4,096 × 2 byte = 32 MiB
- **B = 1** (ஒரு token-க்கு ஒரு முறை — உரை உருவாக்கத்தின்போது பொதுவானது): MAC-கள் = 16,777,216 → 2 FLOP × 16.8 M ÷ 33.5 MB ≈ **1 FLOP/byte**
- **B = 32:** அதே weight-கள், 32 மடங்கு கணக்கு → ≈ **32 FLOP/byte**

பதிவு 54-இன் ridge point (V100-க்கு 17.4 FLOP/byte) உடன் ஒப்பிடுங்கள்: B = 1 தெளிவாக நினைவகத்தால் வரம்பிடப்படுகிறது; B = 32 கணக்கால். ஒரே layer, ஒரே வன்பொருள் — batch அளவு மட்டும் bottleneck-ஐ மாற்றுகிறது. (Activation-களின் போக்குவரத்தை இங்கே புறக்கணித்தோம்.) இதனால்தான் AI வன்பொருள் வடிவமைப்பு "அதிக MAC-கள்" என்பதோடு நிற்காமல் "ஒவ்வொரு எண்ணையும் chip-இல் வைத்து எத்தனை முறை மீண்டும் பயன்படுத்தலாம்" என்பதைச் சுற்றிச் சுழல்கிறது — அடுத்த பதிவின் systolic array அதற்கான ஒரு நேரடிப் பதில்.

## காகிதப் பயிற்சிகள் (விடைகளுடன்)

(பயிற்சிகளில் புதிதாக வரும் உள்ளீட்டு எண்கள், மூலத்துடன் குறிக்கப்பட்டவை தவிர, எடுத்துக்காட்டு மதிப்புகள்.)

1. x = [2, 0, 1], W-இன் நெடுவரிசைகள் [1, 3, −4] மற்றும் [0.5, 1, 1]. ReLU-க்குப் பின் வெளியீடு?
   *விடை:* 2 + 0 − 4 = −2 → 0; 1 + 0 + 1 = 2 → 2. வெளியீடு [0, 2].
2. Batch 8, உள்ளீடு 1,024, வெளியீடு 4,096 layer-க்கு எத்தனை MAC-கள்?
   *விடை:* 8 × 1,024 × 4,096 = 33,554,432.
3. 28 × 28 வெளியீடு, 5 × 5 filter, 32 உள்ளீட்டு channel, 64 வெளியீட்டு channel. im2col matrix அளவும் MAC-களும்?
   *விடை:* வரிசைகள் 784, நெடுவரிசைகள் 5 × 5 × 32 = 800; filter matrix 800 × 64. MAC-கள் = 784 × 800 × 64 = 40,140,800.
