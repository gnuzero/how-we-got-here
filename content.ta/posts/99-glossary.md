# சொற்களஞ்சியம்

*நாம் அங்கு எப்படிச் சென்றடைந்தோம்* முழுவதும் தோன்றும் மிக முக்கியமான சொற்களுக்கான சுருக்கமான குறிப்பு.

**Analytical Engine (பகுப்புப் பொறி)**  
1834-இல் Charles Babbage கருத்துருவாக்கிய, பஞ்ச் கார்டுகளால் நிரலிடக்கூடிய பொது நோக்கு இயந்திரக் கணினி. நினைவகத்தை (store) கணித அலகிலிருந்து (mill) பிரித்தது. முழுமையாகக் கட்டப்படவில்லை.

**Attention (Self-Attention)**  
ஒரு வரிசையில் உள்ள ஒவ்வொரு நிலைக்கும், எல்லா நிலைகளிலும் உள்ள value வெக்டர்களின் எடையிடப்பட்ட தொகையைக் கணிக்கும் பொறிமுறை. எடைகள் query மற்றும் key வெக்டர்களுக்கு இடையேயான ஒற்றுமையிலிருந்து வருகின்றன. Transformer-இன் மையக் கணிப்பு முறை.

**Branch Prediction**  
நிபந்தனைக் கிளைகளின் திசையைப் பற்றிய வன்பொருள் ஊகம்; நிபந்தனை தீர்க்கப்படும் வரை காத்திருக்காமல் பைப்லைன் அறிவுறுத்தல்களைப் பெறவும் செயல்படுத்தவும் தொடர முடியும்.

**Cache**  
சமீபத்தில் பயன்படுத்தப்பட்ட தரவு அல்லது அறிவுறுத்தல்களை வைத்திருக்கும் சிறிய, வேகமான நினைவகம்; செயலி ஒவ்வொரு அணுகலிலும் மிக மெதுவான முதன்மை நினைவகத்திற்காகக் காத்திருக்க வேண்டாம்.

**Chiplet**  
பெரிய தருக்க செயலி அல்லது முடுக்கி உருவாக்க மற்ற chiplets உடன் தொகுக்கப்படும் சிறிய die. மேம்பட்ட செயல்முறை முனைகளில் உற்பத்தி yield-ஐ மேம்படுத்தப் பயன்படுகிறது.

**Combinational Logic**  
வெளியீடுகள் தற்போதைய உள்ளீடுகளை மட்டுமே சார்ந்த தர்க்கம் (முந்தைய நிலையின் நினைவகம் இல்லை). வாயில்களிலிருந்து கட்டப்பட்டது; sequential logic-இன் எதிர்.

**CUDA**  
GPU-களில் பொது நோக்கக் குறியீட்டை இயக்க அனுமதிக்கும் NVIDIA இன் இணைச்செயலாக்க கணினித் தளமும் நிரலாக்க மாதிரியும்.

**Datapath**  
ஒரு அறிவுறுத்தலின் உண்மையான கணிதத்தையும் தரவு நகர்வையும் செய்யும் செயல்பாட்டு அலகுகளின் தொகுப்பு (ALU-கள், பதிவேடுகள், multiplexers போன்றவை).

**Difference Engine (வித்தியாசப் பொறி)**  
முடிவுள்ள வேறுபாடுகள் முறையில், கூட்டல் மட்டுமே கொண்டு பல்லுறுப்புக் கோவைகளின் அட்டவணைகளைக் கணக்கிட்டு அச்சிட Babbage வடிவமைத்த இயந்திரக் கணிப்பான்.

**FinFET**  
சேனல் செங்குத்து “fin” ஆக இருக்கும் டிரான்சிஸ்டர் அமைப்பு. planar MOSFET-களை அடுத்து வந்தது; மிக மேம்பட்ட முனைகளில் Gate-All-Around (GAA) சாதனங்களால் அடுத்து வரப்பட்டது.

**Glyph (எழுத்து வடிவம்)**  
திரையில் அல்லது தாளில் வரையப்படும் ஒரு எழுத்தின் வடிவம். தமிழில் ஒரு எழுத்து பல glyph-களாக வரையப்படலாம் (கொ = ெ + க + ா); Unicode எழுத்தைக் குறியிடுகிறது, glyph-ஐ எழுத்துரு தீர்மானிக்கிறது.

**Instruction Set Architecture (ISA)**  
மென்பொருளுக்கும் வன்பொருளுக்கும் இடையேயான இடைமுகம்: ஒரு செயலி செயல்படுத்தக்கூடிய அறிவுறுத்தல் தொகுப்பு, பதிவேடுகள், நினைவக மாதிரி மற்றும் அழைப்பு மரபுகளுடன்.

**Matrix Multiply-Accumulate (MAC)**  
\(D = A \times B + C\) செயல்பாடு. நவீன நரம்பியல் வலையமைப்புகளில் மேலாதிக்கக் கணித முறை; சிறப்பு அலகுகள் (tensor cores, systolic arrays) இருப்பதற்கான காரணம்.

**Method of Finite Differences (முடிவுள்ள வேறுபாடுகள் முறை)**  
ஒரு n-ஆம் படி பல்லுறுப்புக் கோவையின் n-ஆம் வேறுபாடு மாறிலி என்பதைப் பயன்படுத்தி, அடுத்தடுத்த மதிப்புகளைக் கூட்டல்களால் மட்டுமே கணக்கிடும் முறை.

**Moore’s Law**  
செலவு-திறன் மிக்க சிப்பில் உள்ள டிரான்சிஸ்டர்களின் எண்ணிக்கை சுமார் இரண்டு ஆண்டுகளுக்கு ஒருமுறை இரட்டிப்பாகிறது என்ற கவனிப்பு (மற்றும் பல தசாப்தங்களாகத் தொழில்துறை இலக்கு).

**Movable Type (நகரும் அச்சு)**  
ஒவ்வொரு எழுத்தும் தனித் துண்டாக இருந்து, பக்கத்துக்குப் பக்கம் மீண்டும் அடுக்கிப் பயன்படுத்தப்படும் அச்சு முறை. Shen Kuo-வின் பதிவின்படி Bi Sheng (1041–48) களிமண் அச்சு; தமிழில் முதல் அச்சு நூல் கொல்லம், 1578.

**Out-of-Order Execution**  
அறிவுறுத்தல்கள் நிரல் வரிசையில் அல்லாமல், அவற்றின் operands தயார் ஆன உடனே செயல்படுத்தப்படும் நுண்கட்டமைப்பு நுட்பம்; latency-ஐ மறைக்க.

**Pipeline**  
அறிவுறுத்தல் செயல்பாட்டை நிலைகளாகப் பிரித்தல்; பல அறிவுறுத்தல்கள் ஒரே நேரத்தில் வெவ்வேறு நிலைகளில் இருக்க முடியும், throughput அதிகரிக்கிறது.

**Punched Card (பஞ்ச் கார்டு)**  
துளை / துளையின்மை மூலம் முடிவுகளைக் குறிக்கும் அட்டை. Jacquard தறியில் வடிவத்தையும், Analytical Engine-இல் அறிவுறுத்தல்களையும் சுமந்தது — நிரலை இயந்திரத்திலிருந்து பிரித்த முதல் ஊடகம்.

**Relay**  
மின்னியந்திர சுவிட்ச்: மின்தூண்டப்படும்போது தொடர்பை நகர்த்தும் சுருள். ஆரம்ப டிஜிட்டல் கணினிகளின் மாறுதல் அடிப்படை (Zuse Z3 போன்றவை).

**RISC / CISC**  
Reduced vs Complex Instruction Set Computer. ISA வடிவமைப்பின் இரண்டு வேறுபட்ட தத்துவங்கள்; நவீன உயர்-செயல்திறன் வடிவமைப்புகள் நடைமுறையில் பெரும்பாலும் இணைந்துள்ளன.

**Sequential Logic**  
நினைவகம் கொண்ட தர்க்கம் (flip-flops, latches, பதிவேடுகள்). அதன் வெளியீடுகள் தற்போதைய உள்ளீடுகளையும் முந்தைய நிலையையும் சார்ந்தவை.

**Store / Mill**  
Analytical Engine-இல் எண்களை வைத்திருக்கும் பகுதி (store) மற்றும் கணக்கு நடக்கும் பகுதி (mill) — இன்றைய நினைவகம், CPU ஆகியவற்றின் முன்னோடிகள்.

**Systolic Array**  
அண்டைகளுக்கு தாளமாகக் கணித்துத் தரவை அனுப்பும் செயலாக்கக் கூறுகளின் வழக்கமான கட்டம். அடர்த்தியான matrix multiplication-க்கு மிகத் திறமையானது.

**Tensor Core**  
NVIDIA இன் Volta கட்டமைப்பில் (2017) முதலில் அறிமுகப்படுத்தப்பட்ட சிறப்பு matrix-multiply வன்பொருள் அலகுகள். ஆழ் கற்றலில் பொதுவான கலப்பு-துல்லிய மேட்ரிக்ஸ் செயல்பாடுகளுக்காக வடிவமைக்கப்பட்டவை.

**Transformer**  
“Attention Is All You Need” (2017) இல் அறிமுகப்படுத்தப்பட்ட நரம்பியல் வலையமைப்புக் கட்டமைப்பு. முதன்மையாக self-attention மற்றும் feed-forward அடுக்குகளிலிருந்து கட்டப்பட்டது; நவீன பெரிய மொழி மாதிரிகளின் அடித்தளம்.

**Unicode (யூனிகோட்)**  
உலக எழுத்துகள் ஒவ்வொன்றுக்கும் ஒரு எண் (code point) தரும் தரநிலை. தமிழ் தொகுதி U+0B80–U+0BFF; எழுத்துகள் தர்க்க (உச்சரிப்பு) வரிசையில் சேமிக்கப்படுகின்றன.

**Vacuum Tube (Valve)**  
டிரான்சிஸ்டருக்கு முந்தைய மின்னணு சுவிட்ச்/பெருக்கி. முதல் மின்னணு டிஜிட்டல் கணினிகளில் பயன்படுத்தப்பட்டது (ENIAC போன்றவை). உயர் ஆற்றல், பெரிய அளவு, வரம்பிட்ட நம்பகத்தன்மை.

**Virtual Memory**  
ஒவ்வொரு செயல்முறைக்கும் பெரிய, தொடர்ச்சியான முகவரி இடத்தின் மாயையைத் தரும் நினைவக மேலாண்மை நுட்பம்; வன்பொருளும் இயக்க முறைமையும் அந்த முகவரிகளை இயற்பியல் RAM மற்றும் இரண்டாம்நிலை சேமிப்பில் வரைபடமாக்குகின்றன.
