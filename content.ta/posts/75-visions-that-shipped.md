இந்தப் புத்தகத்தின் spine attention-இல் முடிகிறது. வெளியுலகம் glossary-க்காக நிற்கவில்லை. இந்தக் கடைசி அசைவு **முன் இணைப்புகளின்** தொகுப்பு — பெயரிடப்பட்ட பார்வைகள் stack-இன் துண்டுகளை மக்கள் உண்மையில் உள்ளே வாழும் பொருள்களாக மாற்றிய விதம். வாழ்க்கை வரலாறுகள் அல்ல. MBA பாடநூல் அல்ல. ஒரு *வகையின்* விதைகள்; உறவினர்களைத் தருவித்து நிறுத்துங்கள்.

> **தமிழ் இடைவெளிக் குறிப்பு:** gaps.md இந்தப் பதிவுக்கு Memex (எழுத்து இல்லை, காணொளி இல்லை), Mother of All Demos / Douglas Engelbart (எழுத்து குறைவு, காணொளி இல்லை), Hypertext / WWW (எழுத்தும் காணொளியும் போதுமானவை) என்ற வரிசைகளைப் பட்டியலிடுகிறது (காணொளித் தேடல்: YouTube தேடல் முடிவுகள் மட்டும் — காணொளிகள் பார்க்கப்படவில்லை). ஆனால் ஆங்கிலப் பதிவு Memex-ஐயோ Engelbart-ஐயோ பேசவில்லை — Cisco, Microsoft, Apple, GNU/Linux, Amazon/Musk ஆகிய "முன் இணைப்புகள்" மட்டுமே. பதிவுக்கு உண்மையாக இருக்க, இந்தச் சேர்க்கை அந்தப் பார்வைகளுக்குப் பின்னால் உள்ள பொறியியலை மட்டும் சிறு கணக்குகளால் விளக்குகிறது; Memex / Engelbart இடைவெளி ஆங்கில உள்ளடக்க முடிவுக்கு விடப்படுகிறது. சரிபார்த்த மூலங்கள்: RFC 4632 (CIDR; "longest-match" forwarding விதி), Linux v0.12 release notes (kernel.org பழைய பதிப்புகள் காப்பகம்), GNU "What is Free Software?" பக்கம் (நான்கு சுதந்திரங்கள்). மற்ற எண்கள் "எடுத்துக்காட்டு மதிப்புகள்". இந்தப் பதிவுக்கு lab இல்லை; காகிதப் பயிற்சிகள் கீழே.

## முதலில் சொற்கள்

- **Router (வழிச்செலுத்தி):** ஒவ்வொரு packet-இன் இலக்கு முகவரியைப் பார்த்து, அடுத்த இணைப்பைத் தேர்ந்தெடுக்கும் சாதனம்.
- **Prefix / longest match (முன்னொட்டு / நீளமான பொருத்தம்):** 10.1.0.0/16 போன்ற முகவரித் தொகுதி; பல பொருந்தினால் மிக நீளமான prefix வெல்லும்.
- **Platform / API:** பல நிரல்கள் நம்பிக் கட்டும் பொது அடித்தளம் / அதை அழைக்கும் ஒப்பந்த இடைமுகம்.
- **Lock-in (பூட்டிவைப்பு):** ஒரு platform-இலிருந்து வெளியேறும் செலவு மிக அதிகமாவது.
- **Vertical integration (செங்குத்து ஒருங்கிணைப்பு):** வன்பொருள், OS, பயன்பாட்டு அனுபவம் அனைத்தையும் ஒரே நிறுவனம் வடிவமைப்பது.
- **Copyleft:** மாற்றிய பதிப்புகளும் அதே சுதந்திரங்களுடன் பகிரப்பட வேண்டும் என்ற உரிம நிபந்தனை (GPL).
- **Utilization (பயன்பாட்டு விகிதம்):** வாங்கிய திறனில் உண்மையில் பயன்படும் பங்கு.

## Cisco — வணிகமாக Internetworks

பதிவுகள் 39–41 நெறிமுறைப் பந்தயம். **Cisco** (Leonard Bosack மற்றும் Sandy Lerner, 1980களின் நடுப்பகுதி) multiprotocol routing நீங்கள் வாங்கக்கூடிய பொருளாகும்போது நடப்பது: internetwork கதையின் வணிகப் பொருளாக router. உறவினர்களைத் தருவித்து நிறுத்துங்கள் — மற்ற networking விற்பனையாளர்களும் carrier உபகரண வரிசைகளும் அதே *வகை* (பன்முக nets இடையே glue-ஐ ஒரு தயாரிப்பாக வெளியிடுங்கள்), மனப்பாடப் பட்டியல் அல்ல.

**Router என்ன கணக்கிடுகிறது.** RFC 4632 (CIDR): "Forwarding in the Internet is done on a longest-match basis." ஒரு சிறு அட்டவணை (எடுத்துக்காட்டு மதிப்புகள்):

| Prefix | அடுத்த இணைப்பு |
|---|---|
| 10.0.0.0/8 | A |
| 10.1.0.0/16 | B |
| 10.1.2.0/24 | C |
| 0.0.0.0/0 (default) | D |

| இலக்கு | பொருந்தும் prefix-கள் | நீளமானது | தேர்வு |
|---|---|---|---|
| 10.1.2.7 | /8, /16, /24, /0 | /24 | **C** |
| 10.1.9.9 | /8, /16, /0 | /16 | **B** |
| 10.200.0.1 | /8, /0 | /8 | **A** |
| 192.0.2.1 | /0 மட்டும் | /0 | **D** |

ஒவ்வொரு packet-க்கும் இந்த முடிவு எடுக்கப்பட வேண்டும். "வாங்கக்கூடிய router" என்பது இந்தக் கணக்கை (பல நெறிமுறைகளுக்கும்) நம்பகமான பெட்டியாக்குவது.

## Bill Gates / Microsoft — வெகுஜன Platform ஆக Software

தனிப்பட்ட இயந்திரங்கள் இருந்ததும், பற்றாக்குறை அடுக்கு சிலிகான் மட்டும் அல்ல — எல்லோரும் கருதக்கூடிய software சூழல். **Bill Gates** மற்றும் **Microsoft** commodity PC-களின் மேல் வெகுஜன platform ஆக operating systems மற்றும் கருவிகளைத் தள்ளினர்: API மற்றும் ecosystem, ஒற்றை vertical இயந்திரம் அல்ல, lock-in மேற்பரப்பாகும் பந்தயம். உறவினர்களைத் தருவித்து (அக்காலத்தின் மற்ற வெகுஜன OS/app platforms) நிறுத்துங்கள்.

**API ஏன் பூட்டிவைப்பு மேற்பரப்பு (எடுத்துக்காட்டு மதிப்புகள்).** 100 பயன்பாடுகள், 20 வன்பொருள் வகைகள்.

| அமைப்பு | தேவையான port-கள் |
|---|---|
| பொது API இல்லை — ஒவ்வொரு பயன்பாடும் ஒவ்வொரு வன்பொருளுக்கும் | 100 × 20 = **2,000** |
| பொது OS/API — பயன்பாடு API-க்கு ஒருமுறை, OS ஒவ்வொரு வன்பொருளுக்கும் ஒருமுறை | 100 + 20 = **120** |

பெருக்கல் கூட்டலாகிறது. ஆனால் அதே காரணத்தால், 100 பயன்பாடுகளும் அந்த API-ஐ நம்பியிருக்கின்றன — வேறு OS-க்கு மாற, அவை அனைத்தும் மீண்டும் எழுதப்பட வேண்டும். பயனர்கள் பயன்பாடுகளுக்காக வருகிறார்கள், உருவாக்குநர்கள் பயனர்களுக்காக வருகிறார்கள் — அந்தச் சுழற்சிதான் பதிவு சொல்லும் ecosystem.

## Steve Jobs / Apple — ஒருங்கிணைந்த தனிப்பட்ட இயந்திரம்

**Steve Jobs** (தொடக்கத்தில் **Steve Wozniak**-உடன், பின்னர் Apple-இன் industrial-design மற்றும் platform வளைவு) மற்ற வழியில் பந்தயம் கட்டினார்: வன்பொருள், OS மற்றும் தொடர்பு மாதிரியை ஒருங்கிணைத்து *பொருள்* கணினியாக இருக்க, பாகங்களின் பை அல்ல. ஆரம்ப Apple இயந்திரங்களிலிருந்து பிந்தைய phone-வகுப்பு ஒருங்கிணைந்த சாதனங்கள் வரை, வடிவம் vertical ஒத்திசைவு — அனுபவம் ஒரு அமைப்புகள் பிரச்சினையாக. உறவினர்களைத் தருவித்து (மற்ற ஒருங்கிணைந்த தனிப்பட்ட-சாதன வரிசைகள்) நிறுத்துங்கள்.

## GNU + Linus — இந்தப் புத்தகம் ஏற்கனவே நிற்கும் Free/Open Stack

பதிவு 23 ஏற்கனவே **Richard Stallman**-ஐ (GNU, GPL) மற்றும் **Linus Torvalds**-ஐ (Linux kernel, 1992 ஆரம்பத்தில் GPL relicensing) பெயரிட்டது. புத்தக முடிவுக்கு முன் இணைப்பு மட்டும் தேவை: நவீன platforms கீழ் servers, clouds, phones மற்றும் toolchains அதிகமாக அந்த free/open stack மீது அமர்கின்றன. நடைமுறைக்கு வந்த பார்வை ஒரு பிராண்ட் அல்ல — அது மீதமுள்ள தொழில் கட்டிய சட்ட மற்றும் பொறியியல் பொதுவெளி.

**GPL எதை உறுதி செய்கிறது.** GNU-வின் வரையறைப்படி நான்கு அடிப்படைச் சுதந்திரங்கள்:

| எண் | சுதந்திரம் |
|---|---|
| 0 | நிரலை எந்த நோக்கத்துக்கும் விரும்பியபடி இயக்குதல் |
| 1 | நிரல் எப்படி வேலை செய்கிறது என்று படித்து மாற்றுதல் (source code முன்நிபந்தனை) |
| 2 | பிறருக்கு உதவப் பிரதிகளை மறுவிநியோகம் செய்தல் |
| 3 | மாற்றிய பதிப்புகளின் பிரதிகளைப் பிறருக்கு விநியோகித்தல் (source code முன்நிபந்தனை) |

Copyleft இவை மாற்றிய பதிப்புகளுக்கும் தொடர்வதை உறுதி செய்கிறது. Linux v0.12 release notes-இல் Linus Torvalds எழுதினார்: "you may not distribute it for money" நிபந்தனையை நீக்கி GNU copyleft-உடன் இணக்கமாக்கக் கோரிக்கைகள் வந்தன; அவர் ஒப்புக்கொண்டார்; உதவியவர்களின் ஒப்புதலுக்கு உட்பட்டு "the GNU copyleft takes effect as of the first of February". பதிவு சொல்லும் "1992 ஆரம்பத்தில் GPL relicensing" அதுவே.

## Elon Musk மற்றும் Jeff Bezos — அளவின் நிகழ்கால விதைகள்

**Jeff Bezos** / Amazon ஒரு *வகையின்* விதை: logistics மற்றும் சில்லறைக் கோரிக்கை உலக அளவில் software மற்றும் datacenter platform-ஐ (பின்னர் வாடகை ஒன்றை) கட்டாயப்படுத்தியது — நீங்கள் ஏற்கனவே படித்த விநியோகிக்கப்பட்ட அமைப்புகள் அத்தியாயங்களின் productization ஆக cloud. **Elon Musk** மற்றொரு நிகழ்கால *வகையின்* விதை: software, உற்பத்தி, ஆற்றல் மற்றும் விண்வெளியை தனித் தொழில்களாக அல்ல, ஒரே இணைந்த stack ஆகக் கருதும் நிறுவனங்கள். அளவு, logistics, உள்கட்டமைப்பு மற்றும் product-க்குப் பின்னால் உள்ள platform-இல் peers-ஐத் தருவிக்க அவர்களைப் பயன்படுத்துங்கள் — பிறகு நிறுத்துங்கள். Fan பக்கங்கள் அல்ல. மதிப்பெண் அட்டை அல்ல.

**Cloud ஏன் ஒரு பொருளாகிறது (எடுத்துக்காட்டு மதிப்புகள்).** 10 நிறுவனங்கள்; ஒவ்வொன்றின் உச்சத் தேவை 100 server-கள், சராசரித் தேவை 30. ஒவ்வொன்றும் தன் உச்சத்துக்கு வாங்கினால்:

- மொத்தம் 10 × 100 = **1,000 server-கள்**; பயன்பாட்டு விகிதம் 30 ÷ 100 = **30%**.

உச்சங்கள் ஒரே நேரத்தில் வராததால் பகிரப்பட்ட குளத்துக்கு (ஊகம்) 450 server-கள் போதும் என்றால்:

- சராசரித் தேவை 10 × 30 = 300; பயன்பாட்டு விகிதம் 300 ÷ 450 ≈ **67%**.

இதே பகிர்வு விளைவை ஒரு பெரிய நிறுவனம் தன் உள் platform-இல் கண்டு, பின்னர் அதை வாடகைக்கு விடுவது — பதிவு சொல்லும் "விநியோகிக்கப்பட்ட அமைப்புகளின் productization".

## இந்தக் கதவை எப்படிப் படிப்பது

இந்தப் பெயர்கள் வெளியேற்றங்கள், அத்தியாயங்கள் அல்ல. ஒவ்வொன்றும் புத்தகத்தின் இயந்திரம் வணிகமாகவோ பொதுவெளியாகவோ ஆன இடத்தைச் சுட்டிக்காட்டுகிறது: விற்பனைக்கு internetworks, platform ஆக software, ஒருங்கிணைந்த தனிப்பட்ட இயந்திரங்கள், free/open servers, மற்றும் பிந்தைய-கால அளவுப் பார்வைகள். பதிவு 69 org chart-ஐ வெட்டி பொறியியல் அடுக்குகளைப் பார்க்கும்போது ஒரு *பெரிய platform* எதிலிருந்து ஆனது என்பதைச் சுருக்குகிறது.

## காகிதப் பயிற்சிகள் (விடைகளுடன்)

1. **மேலே உள்ள அட்டவணையில் 10.1.3.255 எங்கே செல்லும்? 10.1.2.255?**
   விடை: 10.1.3.255 — /24 பொருந்தாது (10.1.2.x மட்டும்), /16 பொருந்தும் → **B**. 10.1.2.255 — /24 பொருந்தும் → **C**.

2. **50 பயன்பாடுகள், 8 வன்பொருள் வகைகள் (எடுத்துக்காட்டு மதிப்புகள்). பொது API இல்லாமலும், இருக்கும்போதும் port-கள்?**
   விடை: 50 × 8 = **400**; 50 + 8 = **58**.

3. **GNU வரையறையில் source code அணுகல் எந்த இரு சுதந்திரங்களுக்கு முன்நிபந்தனை?**
   விடை: **சுதந்திரம் 1** (படித்து மாற்றுதல்), **சுதந்திரம் 3** (மாற்றிய பதிப்புகளை விநியோகித்தல்).

4. **Linux v0.12 release notes நீக்க ஒப்புக்கொண்ட நிபந்தனை எது?**
   விடை: "you may not distribute it for money" — பணத்துக்கு விநியோகிக்கத் தடை.

5. **20 நிறுவனங்கள், உச்சம் தலா 50, சராசரி 10; பகிரப்பட்ட குளம் 400 (எடுத்துக்காட்டு மதிப்புகள்). தனித்தனியாகவும் குளத்திலும் பயன்பாட்டு விகிதம்?**
   விடை: தனித்தனி: 10 ÷ 50 = **20%** (மொத்தம் 1,000). குளம்: 20 × 10 = 200; 200 ÷ 400 = **50%**.
