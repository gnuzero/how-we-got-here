# පාරිභාෂික ශබ්දකෝෂය

*රිලේ සිට අවධානය දක්වා* පුරා දිස්වන වැදගත්ම පද සඳහා සංක්ෂිප්ත යොමුවක්.

**Attention (Self-Attention)**  
අනුක්‍රමයක සෑම පිහිටීමක් සඳහාම සියලු පිහිටීම්වල value දෛශිකවල බර තැබූ එකතුවක් ගණනය කරන යාන්ත්‍රණයකි. බර ලැබෙන්නේ query සහ key දෛශික අතර සමානතාවයෙනි. Transformer හි මූලික ගණනය කිරීමේ රටාවයි.

**Branch Prediction**  
කොන්දේසි සහිත ශාඛාවල දිශාව පිළිබඳ දෘඪාංග අනුමානය — කොන්දේසිය විසඳෙන තෙක් නොරැඳී පයිප්ලයින්ට උපදෙස් ලබා ගෙන ක්‍රියාත්මක කිරීමට ඉඩ දෙයි.

**Cache**  
මෑතකදී භාවිතා කළ දත්ත හෝ උපදෙස් තබා ගන්නා කුඩා, වේගවත් මතකයක් — සෑම ප්‍රවේශයකදීම බොහෝ මන්දගාමී ප්‍රධාන මතකය සඳහා සකසනය රැඳී නොසිටින පරිදි.

**Chiplet**  
විශාල තාර්කික සකසනයක් හෝ ත්වරකයක් සෑදීමට අනෙකුත් chiplet සමඟ ඇසුරුම් කරන කුඩා die එකකි. උසස් ක්‍රියාවලි නෝඩ්වල නිෂ්පාදන අස්වැන්න වැඩි දියුණු කිරීමට භාවිතා වේ.

**Combinational Logic**  
ප්‍රතිදාන රඳා පවතින්නේ වත්මන් ආදාන මත පමණි (පෙර තත්වයේ මතකයක් නැත). ගේට් වලින් ගොඩනැගේ; sequential logic හි විරුද්ධයයි.

**CUDA**  
GPU මත සාමාන්‍ය අරමුණු කේතය ධාවනය කිරීමට ඉඩ දෙන NVIDIA හි සමාන්තර පරිගණක වේදිකාව සහ ක්‍රමලේඛන ආකෘතිය.

**Datapath**  
උපදෙසක සැබෑ අංක ගණිතය සහ දත්ත චලනය සිදු කරන ක්‍රියාකාරී ඒකක එකතුව (ALU, රෙජිස්ටර, මල්ටිප්ලෙක්සර් ආදිය).

**FinFET**  
නාලිකාව සිරස් "තුඩ"ක් වන ට්‍රාන්සිස්ටර ව්‍යුහයකි. planar MOSFET අනුප්‍රාප්ත කළ අතර උසස්ම නෝඩ්වලදී Gate-All-Around (GAA) උපාංග මඟින් අනුප්‍රාප්ත විය.

**Instruction Set Architecture (ISA)**  
මෘදුකාංග සහ දෘඪාංග අතර අතුරුමුහුණත: සකසනයක් ක්‍රියාත්මක කළ හැකි උපදෙස් කට්ටලය, රෙජිස්ටර, මතක ආකෘතිය සහ කැඳවුම් සම්මුති සමඟ.

**Matrix Multiply-Accumulate (MAC)**  
\(D = A \times B + C\) මෙහෙයුම. නවීන ස්නායු ජාලවල ප්‍රමුඛ අංක ගණිත රටාව සහ විශේෂිත ඒකක (ටෙන්සර් කෝර්, systolic arrays) පැවතීමට හේතුව.

**Moore’s Law**  
පිරිවැය-ඵලදායී චිපයක ට්‍රාන්සිස්ටර ගණන දළ වශයෙන් සෑම වසර දෙකකට වරක් දෙගුණ වන බව පිළිබඳ නිරීක්ෂණය (සහ දශක ගණනක් කර්මාන්ත ඉලක්කය).

**Out-of-Order Execution**  
operand සූදානම් වූ විගස උපදෙස් ක්‍රියාත්මක කරන ක්ෂුද්‍ර ගෘහ නිර්මාණ ශිල්පීය ක්‍රමයක් — දැඩි වැඩසටහන් අනුපිළිවෙලට නොව, ප්‍රමාදය සැඟවීමට.

**Pipeline**  
උපදෙස් ක්‍රියාත්මක කිරීම අදියරවලට බෙදීම — එකවර අවසන් වීමේ විවිධ අදියරවල බහු උපදෙස් තබා throughput වැඩි කිරීමට.

**Relay**  
විද්‍යුත් යාන්ත්‍රික ස්විචයක්: බලගන්වන විට සම්බන්ධකයක් චලනය කරන කොයිලයක්. මුල් ඩිජිටල් පරිගණකවල (Zuse Z3 ආදිය) මාරු කිරීමේ මූලික ඒකකය.

**RISC / CISC**  
Reduced එදිරිව Complex Instruction Set Computer. ISA නිර්මාණයේ දර්ශන දෙකක්; නවීන ඉහළ කාර්ය සාධන නිර්මාණ ප්‍රායෝගිකව බොහෝ දුරට එකතු වී ඇත.

**Sequential Logic**  
මතකය ඇති තර්කය (ෆ්ලිප්-ෆ්ලොප්, ලැච්, රෙජිස්ටර). ප්‍රතිදාන රඳා පවතින්නේ වත්මන් ආදාන සහ පෙර තත්වය යන දෙක මතයි.

**Systolic Array**  
අසල්වැසියන්ට දත්ත ගණනය කර යවන සැකසුම් මූලද්‍රව්‍යවල නිත්‍ය ජාලයකි. ඝන අනුකෘති ගුණනය සඳහා අතිශය කාර්යක්ෂමයි.

**Tensor Core**  
NVIDIA හි Volta ගෘහ නිර්මාණයේ (2017) ප්‍රථම වරට හඳුන්වා දුන් විශේෂිත අනුකෘති-ගුණන දෘඪාංග ඒකක. ගැඹුරු ඉගෙනීමේ පොදු මිශ්‍ර-නිරවද්‍යතා අනුකෘති මෙහෙයුම් සඳහා නිර්මාණය කර ඇත.

**Transformer**  
"Attention Is All You Need" (2017) හි හඳුන්වා දුන් ස්නායු ජාල ගෘහ නිර්මාණය. ප්‍රධාන වශයෙන් self-attention සහ feed-forward ස්තර වලින් ගොඩනැගේ; නවීන විශාල භාෂා ආකෘතිවල පදනමයි.

**Vacuum Tube (Valve)**  
ට්‍රාන්සිස්ටරයට පෙර පැවති ඉලෙක්ට්‍රොනික ස්විචය/වර්ධකය. පළමු ඉලෙක්ට්‍රොනික ඩිජිටල් පරිගණකවල (ENIAC ආදිය) භාවිතා විය. ඉහළ බලය, විශාල ප්‍රමාණය, සීමිත විශ්වාසනීයත්වය.

**Virtual Memory**  
සෑම ක්‍රියාවලියකටම විශාල, අඛණ්ඩ ලිපින අවකාශයක මායාව ලබා දෙන මතක කළමනාකරණ ශිල්පීය ක්‍රමයක් — දෘඪාංගය සහ මෙහෙයුම් පද්ධතිය එම ලිපින භෞතික RAM සහ ද්විතීය ගබඩාවට සිතියම්ගත කරන අතරතුර.
