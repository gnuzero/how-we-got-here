# පාරිභාෂික ශබ්දකෝෂය

*රිලේ සිට අවධානය දක්වා* පුරා දිස්වන වඩාත්ම වැදගත් පද සඳහා සංක්ෂිප්ත යොමුවක්.

**Attention (Self-Attention / ස්වයං-අවධානය)**  
අනුක්‍රමයක සෑම ස්ථානයක් සඳහාම සියලු ස්ථානවලින් value දෛශිකවල බර යෙදූ එකතුවක් ගණනය කරන යාන්ත්‍රණයකි. බර ලැබෙන්නේ query සහ key දෛශික අතර සමානතාවයෙනි. Transformer හි මූලික ගණනය කිරීමේ රටාව.

**Branch Prediction (ශාඛා පුරෝකථනය)**  
කොන්දේසි සහිත ශාඛාවල දිශාව ගැන දෘඪාංග අනුමානය — කොන්දේසිය විසඳීමට බලා නොසිට පයිප්ලයිනයට උපදෙස් ලබා ගෙන ක්‍රියාත්මක කිරීම දිගටම කරගෙන යාමට.

**Cache (කෑෂ්)**  
මෑතදී භාවිතා කළ දත්ත හෝ උපදෙස් රඳවන කුඩා, වේගවත් මතකයකි — සෑම ප්‍රවේශයකදීම බොහෝ සෙයින් මන්ද මුඛ්‍ය මතකයට බලා සිටීමෙන් සකසනය මුදා හරියි.

**Chiplet (චිප්ලෙට්)**  
විශාල තාර්කික සකසනයක් හෝ ත්වරකයක් සෑදීමට අනෙකුත් chiplet සමඟ ඇසුරුම් කරන කුඩා die එකකි. උසස් ක්‍රියාවලි නෝඩ්වල නිෂ්පාදන අස්වැන්න වැඩි දියුණු කිරීමට භාවිතා වේ.

**Combinational Logic (සංයෝජන තර්කය)**  
ප්‍රතිදාන රඳා පවතින්නේ වත්මන් ආදාන මත පමණි (පෙර තත්ත්වයේ මතකයක් නැත). ගේට් වලින් ගොඩනැගේ; අනුක්‍රමික තර්කයට විරුද්ධයි.

**CUDA**  
GPU මත සාමාන්‍ය අරමුණු කේතය ධාවනය කිරීමට ඉඩ දෙන NVIDIA හි සමාන්තර පරිගණක වේදිකාව සහ ක්‍රමලේඛන ආකෘතිය.

**Datapath (දත්ත මාර්ගය)**  
උපදෙසක සැබෑ ගණිතය සහ දත්ත චලනය සිදු කරන ක්‍රියාකාරී ඒකක (ALU, රෙජිස්ටර, මල්ටිප්ලෙක්සර් ආදිය) එකතුව.

**FinFET**  
නාලිකාව සිරස් “fin” එකක් වන ට්‍රාන්සිස්ටර ව්‍යුහයකි. තල MOSFET අනුප්‍රාප්ත කළ අතර, වඩාත්ම උසස් නෝඩ්වල Gate-All-Around (GAA) උපාංග මඟින් එයම අනුප්‍රාප්ත විය.

**Instruction Set Architecture (ISA / උපදෙස් කට්ට ගෘහ නිර්මාණය)**  
මෘදුකාංග සහ දෘඪාංග අතර අතුරුමුහුණත: සකසනයක් ක්‍රියාත්මක කළ හැකි උපදෙස් කට්ටලය, රෙජිස්ටර, මතක ආකෘතිය සහ ඇමතුම් සම්මුති සමඟ.

**Matrix Multiply-Accumulate (MAC / අනුකෘති ගුණන-සමුච්චය)**  
මෙහෙයුම \(D = A \times B + C\). නවීන ස්නායු ජාලවල ප්‍රමුඛ ගණිත රටාව සහ විශේෂිත ඒකක (ටෙන්සර් කෝර්, සිස්ටොලික් අරා) පවතින හේතුව.

**Moore’s Law (මුවර්ගේ නියමය)**  
පිරිවැය-කාර්යක්ෂම චිපයක ට්‍රාන්සිස්ටර ගණන ආසන්න වශයෙන් සෑම වසර දෙකකට වරක් දෙගුණ වේ යන නිරීක්ෂණය (සහ දශක ගණනක් කර්මාන්ත ඉලක්කය).

**Out-of-Order Execution (අනුපිළිවෙලට-පිට ක්‍රියාත්මක කිරීම)**  
ප්‍රමාදය සැඟවීමට, වැඩසටහන් අනුපිළිවෙලට දැඩි ලෙස නොව, operands සූදානම් වූ විගස උපදෙස් ක්‍රියාත්මක කරන ක්ෂුද්‍ර-ගෘහ නිර්මාණ ශිල්පයක්.

**Pipeline (පයිප්ලයිනය)**  
උපදෙස් ක්‍රියාත්මක කිරීම අදියරවලට බෙදීම — එකවර උපදෙස් කිහිපයක් විවිධ අදියරවල සිටීමට ඉඩ දී ප්‍රතිදානය වැඩි කිරීම.

**Relay (රිලේ)**  
විද්‍යුත් යාන්ත්‍රික ස්විචයක්: ශක්තිමත් කළ විට සම්බන්ධකයක් චලනය කරන කොයිලයක්. මුල් ඩිජිටල් පරිගණකවල (Zuse Z3 ආදිය) මාරු කිරීමේ මූලික ඒකකය.

**RISC / CISC**  
Reduced vs Complex Instruction Set Computer. ISA නිර්මාණයේ විවිධ දර්ශන දෙකක්; නවීන ඉහළ-කාර්ය සාධන නිර්මාණ ප්‍රායෝගිකව බොහෝ දුරට අභිසාරී වී ඇත.

**Sequential Logic (අනුක්‍රමික තර්කය)**  
මතකය ඇති තර්කය (ෆ්ලිප්-ෆ්ලොප්, ලැච්, රෙජිස්ටර). එහි ප්‍රතිදාන රඳා පවතින්නේ වත්මන් ආදාන සහ පෙර තත්ත්වය යන දෙක මතමයි.

**Systolic Array (සිස්ටොලික් අරාව)**  
දත්ත අසල්වැසියන්ට රිද්මයානුකූලව ගණනය කර යවන සැකසුම් මූලද්‍රව්‍යවල නිතිපතා ජාලයක්. ඝන අනුකෘති ගුණනය සඳහා අතිශය කාර්යක්ෂමයි.

**Tensor Core (ටෙන්සර් කෝර්)**  
NVIDIA හි Volta ගෘහ නිර්මාණයේ (2017) මුලින්ම හඳුන්වා දුන් විශේෂිත අනුකෘති-ගුණන දෘඪාංග ඒකක. ගැඹුරු ඉගෙනීමේදී පොදු මිශ්‍ර-නිරවද්‍යතා අනුකෘති මෙහෙයුම් සඳහා නිර්මාණය කර ඇත.

**Transformer**  
“Attention Is All You Need” (2017) හි හඳුන්වා දුන් ස්නායු ජාල ගෘහ නිර්මාණය. ප්‍රධාන වශයෙන් ස්වයං-අවධානය සහ feed-forward ස්ථර වලින් ගොඩනැගේ; නවීන විශාල භාෂා ආකෘතිවල පදනම.

**Vacuum Tube (Valve / රික්තක නලය)**  
ට්‍රාන්සිස්ටරයට පෙර තිබූ ඉලෙක්ට්‍රොනික ස්විචය/ඇම්ප්ලිෆයර් එකකි. පළමු ඉලෙක්ට්‍රොනික ඩිජිටල් පරිගණකවල (ENIAC ආදිය) භාවිතා විය. ඉහළ බලය, විශාල ප්‍රමාණය, සීමිත විශ්වාසනීයත්වය.

**Virtual Memory (අතථ්‍ය මතකය)**  
සෑම ක්‍රියාවලියකටම විශාල, අඛණ්ඩ ලිපින අවකාශයක මායාව ලබා දෙන මතක කළමනාකරණ ශිල්පයක් — දෘඪාංගය සහ මෙහෙයුම් පද්ධතිය එම ලිපින භෞතික RAM සහ ද්විතීය ගබඩාව මත සිතියම්ගත කරන අතරතුර.
