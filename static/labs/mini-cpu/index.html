Assembly

ISA: NOP LDA a ADD a SUB a STA a LDI n JMP a JC a JZ a OUT HLT — addresses/immediates 0–15, written in decimal (13) or hex (0xD)
  • Operands must be whole numbers 0–15. Anything else (0xZZ, 300, a missing address) stops Assemble with an error naming the line — it is never quietly read as 0. NOP, OUT and HLT ignore an operand when they run, so NOP 7 is a way to put the value 7 in memory.
  • ZERO lights when A ends up 0 after LDI, LDA, ADD or SUB. STA, OUT and jumps leave it alone. Reset clears it, so a JZ before any of those falls through.
  • Registers are 8-bit: 0 − 1 wraps to 255 (and sets CARRY). A countdown from n=0 runs 256 loops, not zero.
  • Program and values share the same 16 words. A STA can overwrite an instruction — even your final HLT, and then the CPU runs on past it.
