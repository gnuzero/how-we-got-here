# Difference Engine Lab — Carry

**License:** CC BY 4.0 (same as the book `LICENSE`).

**Origin:** Original interactive for *From Relays to Attention* (Grok Team / Reed labs desk).  
Not a vendored third-party Difference Engine simulator. No nlisgo / Ed Thelen / 101computing / DigiSim / aroman code.

**What it shows:** Method of finite differences for `f(x)=x²` on figure-wheel columns (Y, Δ₁, Δ₂). Each Step is one difference cycle. When a digit rolls 9→0, a carry arm animates the “tooth catching neighbor” moment.

**Not included:** Full Difference Engine No. 2 reconstruction; Analytical Engine (see `../analytical-engine/`, Fourmilab public domain).

**Door-outs (credit/link only):** Science Museum, Computer History Museum, Plan 28.
