VM Terminal Lab

Real x86 machine, running client-side in your browser via WASM — boots a real Linux, real shell, real commands
Not started — press Boot VM

First commands

Press Boot VM, wait for the login/shell prompt, then click the black screen so the keyboard focuses the VM. Try these:

whoami uname ls

Type each command and press Enter. Restart returns you to a fresh boot if the session gets stuck.
