# 我们如何走到那里

中文版正在依据中文一手资料撰写，首批页面即将上线。

中文版不是英文版的译本。中文与英文同为本书的权威来源语言，采用相同的证据标准；资料来源涵盖中国大陆、台湾和香港。

本版提供简体与繁体两种版本。简体为母本，繁体由简体转换后再经术语审校。所有中文内容在定稿前都会由母语读者人工校对。

首批页面上线之前，可以先阅读[英文版]({{< relref path="/" lang="en" >}})。

本书的主线是一条连续的工程论证：每个时代最难的约束，如何逼出下一种架构。

**印刷 → 传递 → 机械 → 摄影 → 继电器 → 电子管 → 晶体管 → CPU → 操作系统与语言 → 总线 → 网络 → 互连与扩展 → GPU → 注意力机制。**

## 先动手

开篇几章刻意写得短，也还不需要动手。印刷、传递、机械、摄影和继电器先把论证铺好，之后实验室才请你动手搭建。读到继电器时，你已经知道被开关的是什么，以及为什么。

## 规律

开篇把同一个动作展示了五次。印刷让一页文字不用抄写员也能复制。电线让一条消息不用骑手也能传送。卡片和齿轮让一件重复的活儿不用人看守也能运转。相机让光自己留下图像，不用任何人移动墨。然后继电器让开关成为电能完成的工作。每一步都把人从一件工作里撤出来，交给一种材料或一台机器。
