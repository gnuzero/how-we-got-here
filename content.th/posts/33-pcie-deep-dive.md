บทที่ 32 อธิบาย *เหตุใด* PCIe จึงย้ายไปลิงก์อนุกรมแบบจุดต่อจุด บทนี้อธิบาย *ว่า* มันจัดโครงสร้างการสื่อสารบนลิงก์เหล่านั้นอย่างไร — ซึ่งสำคัญโดยตรงสำหรับใครก็ตามที่ทำงานฮาร์ดแวร์จริง รวมถึงโครงการ GPU memory fabric บน Nitefury ที่ชุดบทความนี้กล่าวถึงเป็นระยะ

## สแต็กโปรโตคอลแบบชั้น

PCIe จัดระเบียบการสื่อสารเป็นสามชั้น แต่ละชั้นมีงานต่างกัน **Transaction Layer** คือที่ที่คำขออ่าน/เขียนและการตอบเสร็จสิ้น (completion) เกิดและจบ — ชั้นที่ตรรกะแอปพลิเคชัน (หรือไดรเวอร์อุปกรณ์) โต้ตอบด้วยในเชิงแนวคิด **Data Link Layer** อยู่ใต้ชั้นนั้น รับผิดชอบการส่งมอบที่เชื่อถือได้: หมายเลขลำดับ การตรวจ CRC และการส่งซ้ำหากแพ็กเก็ตเสียหายระหว่างทาง — ลิงก์ PCIe คาดว่าจะส่งข้อมูลได้อย่างเชื่อถือได้ และชั้นนี้คือสิ่งที่ทำให้การรับประกันนั้นเป็นจริง **Physical Layer** คือการส่งสัญญาณไฟฟ้าจริง — คู่ดิฟเฟอเรนเชียล การเข้ารหัส 8b/10b หรือ 128b/130b (ขึ้นกับรุ่น PCIe) เพื่อให้สัญญาณสมดุล DC และกู้คืนได้ และการ serialize/deserialize ของกระแสบิตลงบนสายกายภาพ

## Transaction Layer Packet (TLP)

หน่วยพื้นฐานของการสื่อสารคือ Transaction Layer Packet TLP พก header (ระบุประเภททรานแซกชัน — อ่านหน่วยความจำ เขียนหน่วยความจำ คำขอ I/O การเข้าถึงการตั้งค่า — พร้อมที่อยู่เป้าหมายและความยาว) และสำหรับการเขียน พก payload ของข้อมูลจริง Data Link Layer ห่อ TLP นี้ด้วยหมายเลขลำดับและ CRC ก่อนออกไปทาง physical layer และฝั่งรับใช้หมายเลขลำดับกับ CRC เพื่อตรวจจับการหายหรือการเสียหาย แล้วขอส่งซ้ำเมื่อจำเป็น — ทั้งหมดนี้เกิดอย่างโปร่งใสใต้สิ่งที่ จากมุมมองของ transaction layer ดูเหมือนการอ่านหรือเขียนที่เรียบง่ายและเชื่อถือได้

## Lane และรุ่น (Generations)

"lane" ของ PCIe คือคู่สัญญาณดิฟเฟอเรนเชียลหนึ่งคู่ต่อทิศทาง (ส่งและรับ) — หน่วยขั้นต่ำของลิงก์ PCIe หลาย lane สามารถรวมกันได้ (x1, x4, x8, x16) เพื่อคูณแบนด์วิดท์ที่มีสำหรับอุปกรณ์ที่ต้องการ แต่ละ *รุ่น* ของ PCIe ประมาณสองเท่าแบนด์วิดท์ต่อ lane จากรุ่นก่อน ผ่านการผสมของอัตราการส่งสัญญาณที่สูงขึ้นและประสิทธิภาพการเข้ารหัสที่ดีขึ้น — สล็อต x16 Gen 5 พกแบนด์วิดท์ทิศทางเดียวประมาณ 4× ของสล็อต x16 Gen 3 (~64 GB/s เทียบ ~16 GB/s) แม้จำนวน lane กายภาพจะเหมือนกัน ล้วนจากปรับปรุงการส่งสัญญาณข้ามรุ่นเหล่านี้

## เหตุใดสิ่งนี้สำคัญสำหรับโครงการ fabric แบบกำหนดเอง

ใครก็ตามที่สร้างฮาร์ดแวร์กำหนดเองที่พูด PCIe — รวมถึงการ์ด memory fabric บน FPGA กำหนดเอง — ต้องทำงานภายในโครงสร้างแบบชั้นนี้: นำ (หรือใช้ IP block ที่มีอยู่สำหรับ) การ serialize และการเข้ารหัสของ physical layer การรับประกันความเชื่อถือได้ของ data link layer และการสร้างแพ็กเก็ตระดับ transaction ให้ถูกต้องจนระบบนิเวศ PCIe ที่เหลือ (root complex, สวิตช์, endpoint อื่น) ตีความถูก การเข้าใจ TLP โดยเฉพาะสำคัญ เพราะนั่นคือชั้นที่การออกแบบกำหนดเองแสดง *เจตนา* — การอ่านหน่วยความจำ การเขียนหน่วยความจำ ที่อยู่และความยาวที่เกี่ยวข้อง — โดยทุกอย่างใต้ชั้นนั้น (ความเชื่อถือได้ การส่งสัญญาณกายภาพ) ส่วนใหญ่จัดการด้วยตรรกะที่ใช้ซ้ำได้และเป็นที่ยอมรับแล้ว นี่คือชั้นที่การถ่ายโอน peer-to-peer แบบ GPUDirect ซึ่งกล่าวในบทที่ 37 มีความหมาย: TLP ที่ระบุที่อยู่ตรงระหว่าง endpoint PCIe สองตัว โดยไม่ต้องให้ CPU นั่งในเส้นทางข้อมูลเลย
