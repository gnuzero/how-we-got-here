ชื่อชุดบทความนี้คือ *จากรีเลย์สู่ Attention* ทุกอย่างจนถึงจุดนี้คือเส้นทางทางกายภาพและสถาปัตยกรรมอันยาวไกลที่ทำให้การคูณเมทริกซ์ขนาดใหญ่เป็นไปได้จริง บทนี้คือจุดหมายเชิงอัลกอริทึมที่เส้นทางนั้นเปิดทางให้เกิดขึ้น

ในปี 2017 Vaswani et al. ตีพิมพ์ "Attention Is All You Need" งานวิจัยนี้แนะนำสถาปัตยกรรม Transformer และที่สำคัญกว่านั้น คือทำให้ *self-attention* เป็นกลไกหลักในการจำลองลำดับ มันแทนที่การเกิดซ้ำแบบลำดับของ RNN และ LSTM ด้วยการดำเนินการที่ขนานได้อย่างเต็มที่ ซึ่งสามารถมองทุกตำแหน่งในลำดับได้พร้อมกัน

## Self-Attention ทำอะไรจริง ๆ

เมื่อได้ลำดับของ token embedding แล้ว self-attention จะคำนวณ สำหรับทุกตำแหน่ง ผลรวมแบบถ่วงน้ำหนักของค่า (value) จากทุกตำแหน่ง น้ำหนักได้มาจากความคล้ายระหว่างเวกเตอร์ *query* (จากตำแหน่งปัจจุบัน) กับเวกเตอร์ *key* (จากทุกตำแหน่ง) ในรูปเมทริกซ์คือ:

\[
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
\]

- \(Q\), \(K\) และ \(V\) คือการฉายเชิงเส้นของอินพุต
- การหารด้วย \(\sqrt{d_k}\) ช่วยไม่ให้ softmax อิ่มตัวเมื่อมิติใหญ่
- ผลลัพธ์คือลำดับใหม่ที่มีความยาวเท่าเดิม โดยแต่ละตำแหน่งได้รับอนุญาตให้รวบรวมข้อมูลจากตำแหน่งอื่นทั้งหมดในแบบที่ขึ้นกับข้อมูล

เนื่องจากปฏิบัติการนี้แสดงเป็นการคูณเมทริกซ์และ softmax จึงแมปเข้ากับฮาร์ดแวร์ที่ตรวจสอบในบทก่อนหน้าได้ดีมาก: หน่วยคูณเมทริกซ์ปริมาณงานสูง หน่วยความจำบนชิปขนาดใหญ่ และการเชื่อมต่อที่เคลื่อนย้าย activation และน้ำหนักที่จำเป็นได้

## Multi-Head Attention

หัว attention เดียวมักโฟกัสความสัมพันธ์ชนิดเดียว Multi-head attention รันการดำเนินการ attention หลายชุดพร้อมกัน (การฉายที่เรียนรู้ต่างกัน) แล้วต่อผลลัพธ์เข้าด้วยกัน ทำให้แบบจำลองสามารถใส่ใจข้อมูลประเภทต่าง ๆ พร้อมกันได้ — เชิงวากยสัมพันธ์ เชิงความหมาย เชิงตำแหน่ง ระยะไกล ระยะใกล้ — ภายในชั้นเดียวกัน

Transformer ต้นฉบับใช้ 8 หัว LLM สมัยใหม่มักใช้หลายสิบถึงหลักร้อยต่ำของ query head ต่อชั้น (เช่น GPT-3: 96; Llama 3 405B: 128) ซ้อนกันข้ามหลายสิบถึงประมาณ 100+ ชั้น (Llama 3 405B: 126) — ไม่ใช่ "หลายร้อย" ของทั้งสองอย่างเป็นประจำ

## เหตุใดจึงเปลี่ยนทุกอย่าง

คุณสมบัติสามประการทำให้ Transformer เป็นสถาปัตยกรรมลำดับที่ครองสนาม:

1. **ความขนาน** — ต่างจาก RNN ทุกตำแหน่งประมวลผลพร้อมกันได้ ปริมาณงานในการเทรนปรับตามความยาวลำดับและความจุคูณเมทริกซ์ของฮาร์ดแวร์ แทนที่จะถูกจำกัดด้วยขั้นตอนตามลำดับ
2. **การพึ่งพาระยะไกล** — โดยหลักการ โทเคนใดก็ใส่ใจโทเคนอื่นได้โดยตรง จำกัดเพียงต้นทุนกำลังสองของเมทริกซ์ attention และ context window ในทางปฏิบัติ
3. **ความเข้ากันได้กับฮาร์ดแวร์** — การดำเนินการหลักคือการคูณเมทริกซ์หนาแน่น นี่คือสิ่งที่ tensor core, systolic array และลำดับชั้นหน่วยความจำ GPU สมัยใหม่ถูกปรับให้เหมาะสม (ดูบทที่ 55–58)

ต้นทุนกำลังสองของ full attention ยังคงเป็นข้อจำกัดจริง นั่นจึงเป็นเหตุที่งานภายหลังเรื่อง sparse attention, linear attention, sliding-window attention และ approximation อื่น ๆ เข้มข้น แต่ข้อสังเกตหลัก — ว่ากลไก attention ที่เรียบง่ายและขนานได้สามารถแทนที่การเกิดซ้ำได้ — ยังคงยืนอยู่

## การปิดเส้นโค้ง

จากรีเลย์แม่เหล็กไฟฟ้าตัวแรกที่ทำให้ตรรกะบูลีนเป็นจริงได้ ผ่านหลอดสุญญากาศ ทรานซิสเตอร์ ไปป์ไลน์ แคช GPU และ tensor core เส้นทางฮาร์ดแวร์คือการทำให้การสลับ การเก็บ และการคำนวณเลขคณิตเร็วขึ้น หนาแน่นขึ้น และมีประสิทธิภาพมากขึ้น Attention คือโครงสร้างเชิงอัลกอริทึมที่ปัจจุบันดึงคุณค่าจากฮาร์ดแวร์นั้นได้มากที่สุดสำหรับการจำลองลำดับ

ข้อจำกัดทางกายภาพยังคงเปลี่ยนไป (แบนด์วิดท์หน่วยความจำ พลังงานต่อปฏิบัติการ ความหน่วงของการเชื่อมต่อ) การตอบสนองทางวิศวกรรมยังคงเป็นรูปแบบเดียวกันตั้งแต่ต้นชุดนี้: ระบุข้อจำกัดที่ผูกมัดให้แม่นยำ แล้วเปลี่ยนสถาปัตยกรรม แทนที่จะเพียงผลักแรงกว่าเดิมกับกำแพงเดิม
