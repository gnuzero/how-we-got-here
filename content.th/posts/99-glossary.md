# อภิธานศัพท์

แหล่งอ้างอิงกระชับสำหรับคำสำคัญที่สุดที่ปรากฏทั่ว *เราไปถึงจุดนั้นได้อย่างไร*

**Attention (Self-Attention)**  
กลไกที่คำนวณ สำหรับทุกตำแหน่งในลำดับ ผลรวมแบบถ่วงน้ำหนักของเวกเตอร์ value จากทุกตำแหน่ง น้ำหนักมาจากความคล้ายระหว่างเวกเตอร์ query และ key แบบแผนการคำนวณหลักของ Transformer

**Branch Prediction**  
การคาดการณ์ของฮาร์ดแวร์เกี่ยวกับทิศทางของสาขาแบบมีเงื่อนไข เพื่อให้ไปป์ไลน์ดึงและประมวลผลคำสั่งต่อไปได้โดยไม่ต้องรอให้เงื่อนไขถูกตัดสิน

**Cache**  
หน่วยความจำขนาดเล็กที่เร็ว ซึ่งเก็บข้อมูลหรือคำสั่งที่ใช้ล่าสุด เพื่อให้ตัวประมวลผลไม่ต้องรอหน่วยความจำหลักที่ช้ากว่ามากในทุกการเข้าถึง

**Chiplet**  
ไดย์ขนาดเล็กกว่าที่ถูกแพ็กเกจร่วมกับ chiplet อื่นเพื่อประกอบเป็นตัวประมวลผลหรือตัวเร่งความเร็วเชิงตรรกะขนาดใหญ่กว่า ใช้เพื่อปรับปรุงอัตราผลผลิตการผลิตที่โหนดกระบวนการขั้นสูง

**Combinational Logic**  
ตรรกะที่เอาต์พุตขึ้นกับอินพุตปัจจุบันเท่านั้น (ไม่มีหน่วยความจำของสถานะก่อนหน้า) สร้างจากเกต เป็นสิ่งตรงข้ามกับ sequential logic

**CUDA**  
แพลตฟอร์มการคำนวณขนานและโมเดลการเขียนโปรแกรมของ NVIDIA ที่ให้โค้ดทั่วไปรันบน GPU ได้

**Datapath**  
ชุดของหน่วยฟังก์ชัน (ALU, รีจิสเตอร์, มัลติเพล็กเซอร์ ฯลฯ) ที่ทำการคำนวณเลขคณิตและการเคลื่อนย้ายข้อมูลจริงของคำสั่ง

**FinFET**  
โครงสร้างทรานซิสเตอร์ที่ช่องสัญญาณเป็น “ครีบ” แนวตั้ง สืบทอดต่อจาก planar MOSFET และถูกสืบทอดต่อโดยอุปกรณ์ Gate-All-Around (GAA) ที่โหนดขั้นสูงสุด

**Instruction Set Architecture (ISA)**  
อินเทอร์เฟซระหว่างซอฟต์แวร์กับฮาร์ดแวร์: ชุดคำสั่งที่ตัวประมวลผลรันได้ พร้อมรีจิสเตอร์ โมเดลหน่วยความจำ และข้อตกลงการเรียกใช้

**Matrix Multiply-Accumulate (MAC)**  
ปฏิบัติการ \(D = A \times B + C\) แบบแผนเลขคณิตที่ครองโครงข่ายประสาทเทียมสมัยใหม่ และเป็นเหตุที่มีหน่วยเฉพาะทาง (tensor core, systolic array)

**Moore’s Law**  
ข้อสังเกต (และเป็นเป้าหมายอุตสาหกรรมมานานหลายทศวรรษ) ว่าจำนวนทรานซิสเตอร์บนชิปที่คุ้มค่าทางต้นทุนจะเพิ่มประมาณสองเท่าทุกสองปี

**Out-of-Order Execution**  
เทคนิคไมโครสถาปัตยกรรมที่คำสั่งถูกประมวลผลทันทีที่ตัวถูกดำเนินการพร้อม แทนที่จะเคร่งตามลำดับโปรแกรม เพื่อซ่อนความหน่วง

**Pipeline**  
การแบ่งการประมวลผลคำสั่งเป็นขั้น ๆ เพื่อให้หลายคำสั่งอยู่ในขั้นต่างกันของการเสร็จสิ้นพร้อมกัน เพิ่มปริมาณงาน

**Relay**  
สวิตช์ไฟฟ้ากลไก: คอยล์ที่เมื่อจ่ายพลังงานจะขยับหน้าสัมผัส หน่วยสลับพื้นฐานของคอมพิวเตอร์ดิจิทัลยุคแรก (Zuse Z3 ฯลฯ)

**RISC / CISC**  
Reduced เทียบกับ Complex Instruction Set Computer ปรัชญาการออกแบบ ISA สองแบบ; การออกแบบสมรรถนะสูงสมัยใหม่ในทางปฏิบัติได้บรรจบกันเป็นส่วนใหญ่

**Sequential Logic**  
ตรรกะที่มีหน่วยความจำ (ฟลิปฟลอป แลตช์ รีจิสเตอร์) เอาต์พุตขึ้นกับทั้งอินพุตปัจจุบันและสถานะก่อนหน้า

**Systolic Array**  
ตารางสม่ำเสมอขององค์ประกอบประมวลผลที่คำนวณและส่งข้อมูลไปยังเพื่อนบ้านอย่างเป็นจังหวะ มีประสิทธิภาพสูงมากสำหรับการคูณเมทริกซ์หนาแน่น

**Tensor Core**  
หน่วยฮาร์ดแวร์คูณเมทริกซ์เฉพาะทางที่เปิดตัวครั้งแรกในสถาปัตยกรรม Volta ของ NVIDIA (2017) ออกแบบสำหรับปฏิบัติการเมทริกซ์แบบความแม่นยำผสมที่พบบ่อยในการเรียนรู้เชิงลึก

**Transformer**  
สถาปัตยกรรมโครงข่ายประสาทเทียมที่แนะนำใน “Attention Is All You Need” (2017) สร้างหลักจาก self-attention และชั้น feed-forward เป็นรากฐานของแบบจำลองภาษาขนาดใหญ่สมัยใหม่

**Vacuum Tube (Valve)**  
สวิตช์/แอมป์อิเล็กทรอนิกส์ที่มาก่อนทรานซิสเตอร์ ใช้ในคอมพิวเตอร์ดิจิทัลอิเล็กทรอนิกส์รุ่นแรก (ENIAC ฯลฯ) ใช้พลังงานสูง ขนาดใหญ่ ความน่าเชื่อถือจำกัด

**Virtual Memory**  
เทคนิคจัดการหน่วยความจำที่ให้แต่ละโปรเซสรู้สึกว่ามีพื้นที่ที่อยู่ขนาดใหญ่ต่อเนื่อง ในขณะที่ฮาร์ดแวร์และระบบปฏิบัติการแมปที่อยู่เหล่านั้นไปยัง RAM จริงและที่เก็บทุติยภูมิ
