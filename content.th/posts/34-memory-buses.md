PCIe (บทที่ 32–33) เชื่อม CPU กับอุปกรณ์ขยาย — GPU การ์ดเครือข่าย ที่เก็บข้อมูล บัสหน่วยความจำเป็นการเชื่อมต่อต่าง และในบางแง่ยิ่งวิกฤตต่อสมรรถนะกว่า: เส้นทางระหว่าง CPU กับหน่วยความจำหลัก (DRAM ที่กล่าวในบทที่ 10) และวิวัฒนาการผ่านรุ่น DDR ต่อเนื่องคือการเจรจาแบบดำเนินอยู่ระหว่างแบนด์วิดท์ latency และพลังงาน

## DDR ย่อมาจากอะไร และเหตุใดจึงสำคัญ

DDR — Double Data Rate — ถ่ายโอนข้อมูลทั้งขอบขาขึ้น *และ* ขอบขาลงของสัญญาณคล็อก ทำให้ throughput เพิ่มเป็นสองเท่าเทียบกับการออกแบบ single-data-rate สมมติที่ความถี่คล็อกเดียวกัน โดยไม่ต้องเพิ่มความเร็วคล็อกจริงเอง นี่เป็นวิธีฉลาดในการได้แบนด์วิดท์มากขึ้นโดยไม่ผลักความถี่คล็อก (และความท้าทายด้านความสมบูรณ์ของสัญญาณที่เกี่ยวข้อง) หนักเท่าที่มิฉะนั้นจะต้องทำ

## วิวัฒนาการข้ามรุ่น: แบนด์วิดท์มากขึ้น Latency คล้ายเดิม

แต่ละรุ่น DDR (DDR3, DDR4, DDR5) ส่งมอบแบนด์วิดท์พีคสูงกว่าเดิมมาก — ขับหลักด้วยอัตรา I/O ที่สูงขึ้น Prefetch คงที่ที่ 8n จาก DDR3 ถึง DDR4; DDR5 เพิ่มเป็นสองเท่าเป็น 16n และแยกแต่ละโมดูลเป็นสอง subchannel 32 บิตอิสระเพื่อ parallelism ที่ดีขึ้น

สิ่งที่พลาดง่ายหากดูเฉพาะตัวเลขแบนด์วิดท์พาดหัว: *latency* การเข้าถึงดิบ — เวลาตั้งแต่ส่งคำขอจนบิตแรกของข้อมูลพร้อม — ปรับปรุงช้ากว่าแบนด์วิดท์มากข้ามรุ่นเดียวกัน นี่คือการตั้งฉากพอดีสำหรับการอภิปราย Memory Wall ในบทที่ 35: DRAM เก่งขึ้นอย่างมากที่ *throughput* ที่ยั่งยืน (เมื่อกระแสข้อมูลเริ่มไหล มันไหลเร็ว) โดยไม่มีการปรับปรุง latency ของการเข้าถึงแรกสุดในกระแสนั้นอย่างเทียบเคียง — เมตริกที่ต่างโดยพื้นฐาน พร้อมคอขวดทางฟิสิกส์ต่างกัน (การ sense ประจุ ฟิสิกส์ตัวเก็บประจุ) อยู่เบื้องหลัง

## Channel, Rank, Bank: โครงสร้างของ Parallelism

*channel* หน่วยความจำคือเส้นทางอิสระจาก memory controller ไปยังชุดอุปกรณ์ DRAM — หลาย channel ให้คำขออิสระเดินหน้าขนานแทนการต่อคิวหลังกัน เพิ่ม throughput ที่มีผลโดยตรงสำหรับ workload ที่ส่งคำขอหน่วยความจำพร้อมกันจำนวนมาก ภายใน channel หน่วยความจำจัดเป็น *rank* (ชุดชิป DRAM อิสระที่เลือกและเข้าถึงได้อิสระในระดับหนึ่ง) และภายใน rank เป็น *bank* (การแบ่งย่อยเพิ่ม ที่ให้ bank หนึ่งยุ่งกับการจบการเข้าถึงก่อน — รวมรอบ refresh ที่บังคับจากบทที่ 10 — ขณะที่ bank อื่นบริการคำขอใหม่ทั้งหมด) โครงสร้างแบบ bank นี้คือสิ่งที่ให้ DRAM คง throughput สูงพอสมควรได้ แม้แต่ละการเข้าถึง bank จะมี latency จริงที่ไม่น้อย — ทับซ้อนการเข้าถึง bank อิสระพอ และ *throughput รวม* คงสูงได้แม้ไม่มี access ใดเร็วขึ้นเป็นรายตัว

## DIMM ในฐานะแพ็กเกจกายภาพ

DIMM (Dual In-line Memory Module) บรรจุชิป DRAM หลายตัวบนแผงวงจรเดียวพร้อม pinout และตัวเชื่อมขอบมาตรฐาน ให้ความจุหน่วยความจำของระบบตั้งค่าและอัปเกรดได้โดยสลับโมดูลกายภาพ — ความสะดวกในการบรรจุที่วางทับทุกสิ่งข้างบน และเหตุผลที่ "ระบบนี้มี RAM เท่าไร" มักตอบได้ด้วยการนับสล็อต DIMM ที่ใส่และความจุของแต่ละตัว

วิวัฒนาการทั้งหมดนี้ — แบนด์วิดท์มากขึ้น parallelism แบบ bank และ prefetch กว้างขึ้นพร้อม dual subchannel ของ DDR5 — คือความพยายามต่อเนื่องของ DRAM ที่จะตามทัน CPU ที่เร็วขึ้นเรื่อย ๆ สองบทถัดไปตรวจสอบสิ่งที่เกิดเมื่อความพยายามนั้นไม่พอ: memory wall และลูกพี่ลูกน้องใกล้ชิดอย่าง clock speed wall
