เฟสสุดท้ายนี้เกี่ยวกับฮาร์ดแวร์ที่สร้างมาเฉพาะสำหรับ workload AI สมัยใหม่ การเข้าใจว่าเหตุใดการออกแบบชิปจึงโค้งแรงในทิศนี้ต้องการความแม่นยำว่า "workload AI" ลดลงเป็นอะไรจริงที่ระดับเลขคณิต — และคำตอบตรงไปตรงมาแคบกว่า และกลไกกว่า ที่วลี "ปัญญาประดิษฐ์" มักสื่อ

## ชั้นโครงข่ายประสาทคำนวณอะไรจริง ๆ

ถอดกรอบออก การผ่านไปข้างหน้าของชั้นโครงข่ายประสาทแบบ fully-connected คือการคูณเมทริกซ์: activation อินพุต (เวกเตอร์ หรือแบตช์ของเวกเตอร์ที่รวมเป็นเมทริกซ์) คูณด้วยเมทริกซ์น้ำหนัก ให้ activation เอาต์พุต โดยปกติตามด้วยฟังก์ชันไม่เชิงเส้นค่อนข้างถูกที่ทำทีละองค์ประกอบ ชั้น convolutional reformulate เป็นการคูณเมทริกซ์ได้เช่นกัน (ผ่าน im2col ซึ่งจัดโครงสร้าง convolution ใหม่เป็นรูปคูณเมทริกซ์เทียบเท่า) กลไก attention — แก่นของสถาปัตยกรรม transformer ที่รองรับแบบจำลองภาษาขนาดใหญ่สมัยใหม่ส่วนใหญ่ — เช่นกัน ที่แก่นการคำนวณ สร้างจากการคูณเมทริกซ์: คำนวณคะแนนความคล้าย query-key แล้วรวมเวกเตอร์ value ที่ถ่วงด้วยคะแนนเหล่านั้น นี่ไม่ใช่การทำให้เข้าใจง่ายเพื่อสอน ส่วนใหญ่ท่วมท้นของรอบ compute ดิบในการเรียนรู้เชิงลึกสมัยใหม่ ทั้งฝึกและ inference คือปฏิบัติการ matrix multiply-accumulate ที่สเกลมหาศาล และถูกทำซ้ำจำนวนมหาศาล

## เหตุใดสิ่งนี้สำคัญต่อการออกแบบฮาร์ดแวร์

คอร์ CPU อเนกประสงค์ (เฟส 3) ถูกสร้างมาจัดการโค้ดลำดับใดก็ได้ได้ดี — สาขา แบบแผนการเข้าถึงหน่วยความจำหลาก การไหลควบคุมที่คาดเดาไม่ได้อย่างแท้จริง ความอเนกประสงค์นั้นมีต้นทุนจริง: สัดส่วนที่มีความหมายของพื้นที่ซิลิคอนและงบพลังงานของคอร์ CPU ไปที่เครื่องจักร (การทำนายสาขา การรันนอกลำดับ การแคชซับซ้อน) ที่ไม่จำเป็นเลยหาก workload ท่วมท้นเป็นปฏิบัติการเฉพาะหนึ่งอย่าง สม่ำเสมอมาก ทำเป็นพันล้านครั้ง ด้วยแบบแผนการเข้าถึงหน่วยความจำที่คาดเดาได้

เมื่อการคูณเมทริกซ์ถูกยอมรับว่าเป็นส่วนครองของ compute AI มันกลายเป็นเป้าที่คุ้มสำหรับฮาร์ดแวร์เฉพาะทาง — ซิลิคอนที่ข้ามเครื่องจักรอเนกประสงค์ที่ CPU ต้องการสำหรับโค้ดใดก็ได้ และอุทิศพื้นที่และงบพลังงานเกือบทั้งหมดให้ปริมาณงาน matrix multiply-accumulate Tensor core (บทที่ 55) คือ implementation รูปธรรมหนึ่งของไอเดียนี้ ฝังในสถาปัตยกรรม GPU ที่ยังอเนกประสงค์อยู่ บทถัดไปครอบคลุมโครงสร้างต่าง ที่รุนแรงกว่า สร้างรอบการตระหนักเดียวกัน — systolic array — ซึ่งเอา "เฉพาะทางทั้งหมดเพื่อการคูณเมทริกซ์" ไปไกลกว่าอีก

## แบบแผนทั่วไป ถูกตั้งชื่ออย่างชัด

นี่คือเรื่องพื้นฐานเดียวกันกับการเปลี่ยนจาก superscalar สู่ multicore ของเฟส 3 (บทที่ 17) และการวิวัฒนาการทรานซิสเตอร์จาก planar สู่ FinFET สู่ GAA ของเฟส 8 (บทที่ 49) เล่นอีกครั้งที่ระดับสถาปัตยกรรมชิปทั้งก้อน แทนหน่วยรันหรือเรขาคณิตทรานซิสเตอร์: เมื่อรูปทรงการคำนวณของ workload ถูกเข้าใจดีและครองพอ ฮาร์ดแวร์เฉพาะทางที่สร้างเพื่อรูปทรงนั้นเอาชนะฮาร์ดแวร์อเนกประสงค์ที่ต้องเกร็งจัดการมันเป็นเพียงกรณีหนึ่งในหลายกรณีได้อย่างน่าเชื่อถือ ความครองของการคูณเมทริกซ์ใน workload AI สมัยใหม่คือเหตุผลพอดีที่นวัตกรรมฮาร์ดแวร์ส่วนใหญ่ในที่เหลือของเฟสนี้เป็นซิลิคอนที่สร้างมาเพื่อสิ่งนี้ แทนการปรับปรุงทีละน้อยต่อการออกแบบ CPU อเนกประสงค์ — หรือแม้ GPU อเนกประสงค์
