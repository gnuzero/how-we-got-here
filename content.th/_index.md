# เราไปถึงจุดนั้นได้อย่างไร

ชุดบทความการศึกษาที่ติดตามเส้นทางทั้งหมดของการคำนวณดิจิทัล — ตั้งแต่รีเลย์และหลอดสุญญากาศ ไปจนถึง GPU, Tensor Core และฮาร์ดแวร์ที่ทำให้กลไก Attention ขนาดใหญ่เป็นไปได้ ประกอบด้วย 63 บททางเทคนิค + คำนำ + อภิธานศัพท์ + แล็บเชิงโต้ตอบ

**63 บททางเทคนิค + คำนำ + อภิธานศัพท์ ~45,000 คำ แล็บเชิงโต้ตอบ**

---

## คำนำ

ชุดบทความนี้มีอยู่เพราะเครื่องมือที่เราใช้ทุกวันเพื่อเทรนและรันโครงข่ายประสาทเทียมขนาดใหญ่ไม่ใช่เวทมนตร์ มันคือบทล่าสุดในเรื่องราววิศวกรรมต่อเนื่องที่เริ่มจากเฟืองทองเหลืองและบัตรเจาะ ผ่านรีเลย์และหลอดสุญญากาศ แล้วทรานซิสเตอร์ แล้วไมโครโพรเซสเซอร์ แล้วลำดับชั้นหน่วยความจำ สแต็กเครือข่าย และสุดท้ายคือซิลิคอนเฉพาะทางที่เร่งการคูณเมทริกซ์ในระดับขนาดใหญ่

การเข้าใจเส้นโค้งทั้งหมดนั้นสำคัญ

เมื่อคุณรู้ว่าเหตุใดรีเลย์จึงถูกทิ้งไปเพื่อหลอดสุญญากาศ เหตุใดหลอดสุญญากาศจึงถูกทิ้งไปเพื่อทรานซิสเตอร์ เหตุใดการเพิ่มความถี่ของคอร์เดียวถึงกำแพง และเหตุใดปริมาณงานคูณเมทริกซ์จึงกลายเป็นข้อจำกัดการออกแบบหลักของทศวรรษที่ผ่านมา คุณจะหยุดมองฮาร์ดแวร์ AI สมัยใหม่เป็นกล่องดำ คุณเริ่มเห็นรูปแบบเดิมซ้ำ: ข้อจำกัดทางกายภาพหรือเศรษฐกิจที่แข็งถูกระบุ และสถาปัตยกรรมถูกเปลี่ยน แทนที่จะเพียงผลักแรงกว่าเดิมกับกำแพงเดิม

รูปแบบนั้นคือหัวข้อจริงของชุดบทความนี้

เราครอบคลุมรากฐาน (การคำนวณเชิงกลไก รีเลย์ หลอด เหตุผลทางกายภาพที่เซมิคอนดักเตอร์ต้องชนะ) การสร้าง CPU สมัยใหม่ (ชุดคำสั่ง ไปป์ไลน์ แคช การประมวลผลนอกลำดับ มัลติคอร์) ชั้นซอฟต์แวร์ที่สร้างทับบนนั้น (ระบบปฏิบัติการ ภาษา คอมไพเลอร์ ระบบเรียลไทม์) การเชื่อมต่อที่ทำให้เครื่องแยกกลายเป็นระบบ (บัส PCIe อีเทอร์เน็ต TCP/IP RDMA) และฮาร์ดแวร์เฉพาะทางล่าสุดที่ทำให้แบบจำลองภาษาขนาดใหญ่เป็นไปได้จริง (GPU CUDA tensor core systolic array quantization sparsity การขยายหลาย GPU)

แล็บเชิงโต้ตอบสามชุดรวมอยู่เพื่อให้คุณสัมผัสแนวคิดเหล่านี้ได้โดยตรง: CPU 8 บิตขนาดเล็กที่โปรแกรมได้ บอร์ดทดลองเสมือนสำหรับตรรกะดิจิทัล และสภาพแวดล้อม x86 Linux เต็มรูปแบบที่รันฝั่งไคลเอนต์ในเบราว์เซอร์

ฉบับร่างถูกเขียนในจังหวะต่อเนื่อง ทุกบัญังมีรายการตรวจสอบสินทรัพย์ (ภาพฮีโร่ สคีมาติก วิดีโอสั้นที่เป็นทางเลือก) ข้ออ้างเชิงเทคนิคถูกสุ่มตรวจความถูกต้องทางประวัติศาสตร์และวิศวกรรม แล็บเชิงโต้ตอบเป็นฝั่งไคลเอนต์และใช้งานได้ (พร้อมการพึ่งพา CDN ภายนอกตามปกติสำหรับบอร์ดทดลองและสภาพแวดล้อม VM เต็มรูปแบบ)

## วิธีใช้ชุดบทความนี้

- เริ่มจากต้นหากต้องการรากฐานทางประวัติศาสตร์และกายภาพครบถ้วน  
- กระโดดไปเฟสหลังหากรู้ประวัติยุคแรกอยู่แล้วและสนใจซิลิคอนกับระบบ AI สมัยใหม่มากที่สุด  
- ใช้แล็บเชิงโต้ตอบทุกที่ที่ปรากฏ (หรือเปิดแยกจากส่วน Labs)  

ชุดนี้จัดเป็นเก้าเฟส บททั้ง 62 บทมีอยู่เป็นฉบับร่างแรก

**เฟส 1** — รากฐาน: จากการคำนวณเชิงกลไกสู่หลอดสุญญากาศ  
**เฟส 2** — ฟิสิกส์และอุปกรณ์  
**เฟส 3** — การสร้าง CPU และสถาปัตยกรรมของมัน  
**เฟส 4** — รากฐานซอฟต์แวร์: OS ภาษา และระบบเรียลไทม์  
**เฟส 5** — บัสและสถาปัตยกรรมระบบ  
**เฟส 6** — เครือข่าย: จากลิงก์อนุกรมสู่ RDMA ในศูนย์ข้อมูล  
**เฟส 7** — เทคโนโลยีกระบวนการและการขยายขนาด  
**เฟส 8** — GPU และการผงาดของตัวเร่ง AI  
**เฟส 9** — ทิศทางต่อไป
