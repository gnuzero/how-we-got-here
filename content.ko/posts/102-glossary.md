# 용어집

*How We Got There* 전반에 가장 중요한 용어의 간결한 참조. 한국어 표기 옆에 영어 원어를 둔다.

**어텐션 (Attention / Self-Attention)**  
시퀀스의 모든 위치에 대해, 모든 위치의 값 벡터의 가중 합을 계산하는 메커니즘. 가중치는 쿼리와 키 벡터의 유사성에서 온다. Transformer의 핵심 계산 패턴.

**분기 예측 (Branch Prediction)**  
조건이 풀리기를 기다리지 않고 파이프라인이 페치·실행을 계속할 수 있도록, 조건 분기의 방향을 하드웨어가 추측하는 것.

**캐시 (Cache)**  
최근 사용한 데이터나 명령을 담는 작고 빠른 메모리로, 프로세서가 매번 훨씬 느린 주기억장치를 기다리지 않게 한다.

**칩렛 (Chiplet)**  
다른 칩렛과 함께 패키징되어 더 큰 논리 프로세서나 가속기를 이루는 더 작은 다이. 선단 공정 노드에서 제조 수율을 개선하는 데 쓰인다.

**조합 논리 (Combinational Logic)**  
출력이 현재 입력에만 의존하는 논리(이전 상태의 기억 없음). 게이트로 구성되며, 순차 논리의 반대.

**CUDA**  
범용 코드를 GPU에서 돌릴 수 있게 하는 NVIDIA의 병렬 계산 플랫폼과 프로그래밍 모델.

**데이터패스 (Datapath)**  
명령의 실제 산술과 데이터 이동을 수행하는 기능 유닛(ALU, 레지스터, 멀티플렉서 등)의 집합.

**FinFET**  
채널이 수직 「fin」인 트랜지스터 구조. 평면 MOSFET의 후속이며, 최선단 노드에서는 Gate-All-Around(GAA) 장치에 이어졌다.

**명령 집합 아키텍처 (Instruction Set Architecture, ISA)**  
소프트웨어와 하드웨어의 인터페이스. 프로세서가 실행할 수 있는 명령의 집합과 레지스터, 메모리 모델, 호출 규약.

**행렬 곱-누적 (Matrix Multiply-Accumulate, MAC)**  
연산 \(D = A \times B + C\). 현대 신경망의 지배적 산술 패턴이며, 특화 유닛(텐서 코어, 시스톨릭 어레이)이 존재하는 이유.

**무어의 법칙 (Moore’s Law)**  
비용 효율적 칩의 트랜지스터 수가 대략 2년마다 두 배가 된다는 관찰(그리고 수십 년 산업 목표).

**비순차 실행 (Out-of-Order Execution)**  
명령이 프로그램 순서가 아니라 피연산자가 준비되는 대로 실행되어 지연을 가리는 마이크로아키텍처 기법.

**파이프라인 (Pipeline)**  
명령 실행을 단계로 나누어, 여러 명령이 동시에 다른 완료 단계에 있게 해 처리량을 높인다.

**릴레이 (Relay)**  
전기기계 스위치. 코일에 전원이 들어오면 접점이 움직인다. 초기 디지털 컴퓨터(Zuse Z3 등)의 스위칭 프리미티브.

**RISC / CISC**  
Reduced vs Complex Instruction Set Computer. ISA 설계의 두 철학. 현대 고성능 설계는 실무에서 대체로 수렴했다.

**순차 논리 (Sequential Logic)**  
기억(플립플롭, 래치, 레지스터)이 있는 논리. 출력이 현재 입력과 이전 상태 둘 다에 의존한다.

**시스톨릭 어레이 (Systolic Array)**  
리듬 있게 계산하고 이웃에 데이터를 넘기는 규칙적 처리 요소 격자. 밀집 행렬 곱에 극히 효율적.

**텐서 코어 (Tensor Core)**  
NVIDIA Volta 아키텍처(2017)에서 처음 도입된 특화 행렬 곱 하드웨어 유닛. 딥러닝에 흔한 혼합 정밀도 행렬 연산을 위해 설계됨.

**트랜스포머 (Transformer)**  
“Attention Is All You Need”(2017)에서 소개된 신경망 아키텍처. 주로 셀프 어텐션과 피드포워드 층으로 구성. 현대 대형 언어 모델의 기초.

**진공관 (Vacuum Tube / Valve)**  
트랜지스터 이전의 전자 스위치/증폭기. 첫 전자 디지털 컴퓨터(ENIAC 등)에 쓰였다. 고전력, 큰 크기, 제한된 신뢰성.

**가상 메모리 (Virtual Memory)**  
각 프로세스에 크고 연속된 주소 공간의 환상을 주고, 하드웨어와 운영체제가 그 주소를 물리 RAM과 이차 저장소에 사상하는 메모리 관리 기법.
