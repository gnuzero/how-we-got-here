# पृष्ठप्रतिलिपेः आरभ्य लेपनं यावत्, कपोतेभ्यः तारेषु उपग्रहेभ्यश्च यावत्, रिलेभ्यः (relay) आरभ्य अवधानं याचमानाः यन्त्राणि यावत्:

**वयं कथम् अत्र आगताः।**

पठ्यताम्: [English](/) · [ไทย](/th/) · [සිංහල](/si/) · [தமிழ்](/ta/) · [简体中文](/zh-hans/) · [繁體中文](/zh-hant/) · [Română](/ro/)

> **टिप्पणी (नूतन-पाठकान् प्रति):** एषा संस्कृतसंस्करणस्य आरम्भभूमिः। अध्यायगभीरा रचना यावत् प्रमाणैः साधिता तावदेव विस्तारिता। नवनिर्मिताः पारिभाषिकाः शब्दाः अधः व्याख्याताः। हिन्दी-पृष्ठात् रूपान्तरं नेदम् — स्वतन्त्रं मूलम्।

एषा विश्वकोशः न, अपि तु संवादयात्रा। लेखसंग्रहः न क्रियते; प्रणाल्यः अनुभूयन्ते स्पृश्यन्ते च।

पृष्ठवंशः (spine — मुख्यक्रमः) एकः अविच्छिन्नः अभियांत्रिकी-तर्कः: प्रत्येकस्य युगस्य कठिना बाधा (constraint) अग्रिमवास्तुकलां (architecture) कथं अबलात्कारयत्।

**मुद्रणम् → सन्देशप्राप्तिः → यान्त्रिकम् → प्रकाशचित्रम् / चलच्चित्रम् → रिले (relay) → निर्वातनलिकाः → ट्रान्ज़िस्टर (transistor) → CPU → OS भाषासहितम् → बस (bus) → जालम् → फैब्रिक्-परिमाणम् → GPU → अवधानतन्त्रम् (attention)।**

## लिपिपङ्क्तिः — ब्राह्मीतः देवनागरीम्

एषा संस्कृतसंस्करणं देवनागरीलिप्या लिख्यते। Encyclopaedia Britannica इत्यनुसारेण देवनागरी उत्तरभारतीय-गुप्तलिपितः, अन्ते च ब्राह्मी-वर्णमालिकायाः, विकसिता; सप्तमशतकाद् आरभ्य प्रयुक्ता, एकादशशतकाद् परिणतरूपेण दृश्यते; संस्कृत-प्राकृत-हिन्दी-मराठी-कोङ्कणी-नेपालीभाषाः अस्यां लिख्यन्ते। ([Britannica, "Devanagari"](https://www.britannica.com/topic/Devanagari))

**व्याख्या (interpretation):** अतः अत्र लिपिक्रमः ब्राह्मी → गुप्त → देवनागरी इति स्रोतैः समर्थितः; कल्पितः नास्ति।

## अनुभवः प्रथमम्

प्रारम्भिक-अध्यायाः संक्षिप्ताः हस्तक्रियाहीनाश्च। मुद्रणं, सन्देशवहनं, यान्त्रिकयन्त्राणि, प्रकाशचित्रं, रिले च — प्रयोगशालाः किमपि निर्मातुं ब्रूयुः इत्यतः पूर्वं तर्कं स्थापयन्ति। रिले-प्राप्तौ किं स्विचीकृतं (switched) कस्माच्च इति ज्ञातमेव भवति।

त्रयः क्लायण्ट्-पार्श्व-प्रयोगशालाः मार्गे स्थिताः — पठनं कर्मणि परिणमयन्ति:

- न्यूनतमः 8-bit CPU यः प्रोग्राम् कर्तुं शक्यते
- डिजिटल्-तर्कस्य आभासी ब्रेडबोर्ड्
- ब्राउज़र् मध्ये पूर्णं x86 Linux-पर्यावरणम्

## पद्धतिः (the pattern)

आरम्भः एकां गतिं पञ्चवारं दर्शयति। मुद्रणं लेखकम् विना पृष्ठं प्रतिलिपिं कर्तुं अशक्नुवत्। तारः अश्वारोहिणं विना सन्देशं गमयितुम् अशक्नुवत्। पत्राणि दन्ताश्च कस्यचिद् अवेक्षणं विना कर्म चालयामासुः। कैमरा (camera) केनापि मसीं न चालयित्वा प्रकाशस्य चित्रनिर्माणम् अकरोत्। ततः रिले स्विचीकरणं विद्युत्कर्म अकरोत्। प्रत्येकं पदं नरं एकस्मात् कर्मात् अपसार्य द्रव्ये यन्त्रे वा न्यक्षिपत्।

यदा ज्ञायते यत् रिले नलिकाभ्यः कस्मात् अपससृपे, नलिकाः ट्रान्ज़िस्टरेभ्यः कस्मात्, एक-कोर-आवृत्तिवर्धनं कस्मात् भित्तिं प्रापत्, गतदशके matrix-multiply throughput प्रमुख-रूपरेखा-बाधा कस्मात् अभवत् — तदा आधुनिकं AI-हार्डवेयर कृष्णपेटिकावत् न दृश्यते। सा एव गतिः पुनः पुनः दृश्यते: बाधां नामय, वास्तुकलां परिवर्तय — समानभित्तौ केवलं बलं मा प्रयुङ्क्ष्व।

सा पद्धतिरेव अस्याः यात्रायाः परमं विषयवस्तु।
