# 我們如何走到那裡

中文版正在依據中文一手資料撰寫，首批頁面即將上線。

中文版不是英文版的譯本。中文與英文同為本書的權威來源語言，採用相同的證據標準；資料來源涵蓋中國大陸、臺灣和香港。

本版提供簡體與繁體兩種版本。簡體為母本，繁體由簡體轉換後再經術語審校。所有中文內容在定稿前都會由母語讀者人工校對。

首批頁面上線之前，可以先閱讀[英文版]({{< relref path="/" lang="en" >}})。

本書的主線是一條連續的工程論證：每個時代最難的約束，如何逼出下一種架構。

**印刷 → 傳遞 → 機械 → 攝影 → 繼電器 → 真空管 → 電晶體 → CPU → 作業系統與語言 → 匯流排 → 網路 → 互連與擴展 → GPU → 注意力機制。**

## 先動手

開篇幾章刻意寫得短，也還不需要動手。印刷、傳遞、機械、攝影和繼電器先把論證鋪好，之後實驗室才請你動手搭建。讀到繼電器時，你已經知道被開關的是什麼，以及為什麼。

## 規律

開篇把同一個動作展示了五次。印刷讓一頁文字不用抄寫員也能複製。電線讓一條訊息不用騎手也能傳送。卡片和齒輪讓一件重複的活兒不用人看守也能運轉。相機讓光自己留下影像，不用任何人移動墨。然後繼電器讓開關成為電能完成的工作。每一步都把人從一件工作裡撤出來，交給一種材料或一臺機器。
