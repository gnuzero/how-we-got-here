# Credits & Doors Out

This journey names constraints and people in the chapters. When a topic already has a strong primary, we point out. Wikipedia is a map, not the destination. Thai, Sinhala, and Tamil desks credit published local literature only when it exists — never a name invented to fill a gap.

Team roles (concept, writing, desks) live on [About](/about/). This page is the professional record *before* the Foreword, so no one has to guess who already published this material.

## Standards and primary specs

Living, numbered specs the spine already leans on. One home each — not a catalog of every standards body.

- [RFC Editor](https://www.rfc-editor.org/) and the [IETF](https://www.ietf.org/) — the Request for Comments series (Jon Postel edited it for nearly three decades). Door-outs already in the chapters include [RFC 1](https://www.rfc-editor.org/rfc/rfc1), [RFC 791](https://www.rfc-editor.org/rfc/rfc791), [RFC 793](https://www.rfc-editor.org/rfc/rfc793), [RFC 1034](https://www.rfc-editor.org/rfc/rfc1034), [RFC 1035](https://www.rfc-editor.org/rfc/rfc1035), [RFC 1459](https://www.rfc-editor.org/rfc/rfc1459), [RFC 1591](https://www.rfc-editor.org/rfc/rfc1591), [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749), [RFC 8446](https://www.rfc-editor.org/rfc/rfc8446).
- [IANA](https://www.iana.org/) — protocol parameters and number registries.
- [ICANN](https://www.icann.org/) — names and numbers policy seat.
- [Unicode Consortium](https://www.unicode.org/) — shared character repertoire ([The Unicode Standard](https://www.unicode.org/standard/standard.html)).
- [IEEE](https://www.ieee.org/) — link-layer families such as IEEE 802 (Ethernet, Wi-Fi).
- [W3C](https://www.w3.org/) and [WHATWG](https://whatwg.org/) — web platform meaning.
- [PCI-SIG](https://pcisig.com/) — PCI Express Base Specification.
- [RISC-V International](https://riscv.org/) — the open ISA manual.
- [Free Software Foundation](https://www.gnu.org/licenses/gpl.html) — GNU GPL, the license lineage named in the Unix/Linux chapters.

Chapter door-outs (Baran, Tomasulo, Kung/Leiserson, and the rest) stay *in* those chapters. This page does not reprint them.
